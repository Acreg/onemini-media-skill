# GPT Image 基础系列与 DALL·E

> **Onemini 图片 API 参数参考。** API 地址：`https://api.onemini.top`。更新日期：2026-11-15。

## 调用前准备

先设置正式站 API Key（以下示例使用 Bash）：

```bash
export API_KEY="替换成正式站 API Key"
```

表格中“—”表示未公布枚举或上下限；“未声明”表示没有明确公布默认值。可选参数仍须满足对应模式的条件。

## 先区分模型，不要套用原生 OpenAI 文档

请使用下面列出的精确 ID。`gpt-image-1` 与 `gpt-image-1-official` 是两个不同型号，后者的参数约束不能自动套给前者；`gpt-image-2` 的 `n=1`，而 `gpt-image-2-official` 的允许 `n=1～4`。

## 精确模型 ID

| model（原样填写） | 参数小节 | API 入口 |
| --- | --- | --- |
| `dall-e-3` | 本文第 1 组参数 | `POST /v1/images/generations` |
| `gpt-image-1` | 本文第 1 组参数 | `POST /v1/images/generations` |
| `gpt-image-1.5` | 本文第 1 组参数 | `POST /v1/images/generations` |
| `gpt-image-1-official` | 本文第 2 组参数 | `POST /v1/images/generations` |
| `gpt-image-1.5-official` | 本文第 2 组参数 | `POST /v1/images/generations` |
| `gpt-image-2` | 本文第 3 组参数 | `POST /v1/images/generations` |
| `gpt-image-2-official` | 本文第 4 组参数 | `POST /v1/images/generations` |

## 响应与结果获取

提交接口为 `POST /v1/images/generations`。请求受理后返回 **HTTP 202**，任务号位于 `data.task_id`（也有 `data.id`）。任务号不是图片下载地址。

使用同一 API Key 调用 `GET /v1/media/tasks/{task_id}`；`data.status` 为 `succeeded` 后，普通图片的文件链接位于 `data.result.images[].url[]`。详细状态、轮询与停止流程见 [媒体任务查询、结果下载与请求停止](https://docs-api.onemini.top/9683548m0)。媒体任务号不使用 `/v1/images/tasks/{task_id}` 查询。

## 1. `dall-e-3` / `gpt-image-1` / `gpt-image-1.5`

本组 ID 共享下列字段结构与约束；`model` 应填写所选的完整 ID，不是任选版本后缀。

### 型号参数表

| 参数 | 类型 | 是否必填 | 默认值 | 枚举、范围与结构约束 | 中文说明 |
| --- | --- | --- | --- | --- | --- |
| `model` | 字符串（string） | 必填 | 未声明 | 本节所选精确 model ID | 请求时原样填写本节列出的 ID；不同后缀是不同模型。 |
| `prompt` | 字符串（string） | 否（条件见下） | 未声明 | 最少字符 1 | 描述要生成的画面，或参考图需要如何修改。 生成提示词。 |

### 条件必填、互斥与结构规则

- 根级必填：`model`。
- 文本生成请求请提供 `prompt`。


### 本组基础调用示例

```bash
curl --request POST \
  --url "https://api.onemini.top/v1/images/generations" \
  --header "Authorization: Bearer ${API_KEY}" \
  --header "Content-Type: application/json" \
  --data-raw '{
  "model": "dall-e-3",
  "prompt": "一只橘猫坐在窗边，柔和自然光，画面简洁"
}'
```

调用本组其他型号时，只需把示例 `model` 换成上面同组的精确 ID；不要改成文档标题或自行删除后缀。

## 2. `gpt-image-1-official` / `gpt-image-1.5-official`

本组 ID 共享下列字段结构与约束；`model` 应填写所选的完整 ID，不是任选版本后缀。

**gpt-image-1-official：** 透明背景时输出格式只能为 PNG。原因是本型号基础格式枚举仅 png/jpeg，虽然透明条件另列 png/webp，但两者必须同时满足，webp 仍不在基础枚举内。

**gpt-image-1.5-official：** 透明背景时输出格式只能为 PNG；不要只看条件中出现 webp 就忽略基础 png/jpeg 枚举。

### 型号参数表

| 参数 | 类型 | 是否必填 | 默认值 | 枚举、范围与结构约束 | 中文说明 |
| --- | --- | --- | --- | --- | --- |
| `background` | 字符串（string） | 否（条件见下） | `auto` | 仅 `transparent`、`opaque`、`auto` | 背景方式；具体可用值见约束列。 |
| `image_urls` | 数组<字符串（string）> | 否（条件见下） | 未声明 | 最多元素 15 | 文生图时省略；图生图或编辑时传入可读取的图片地址。 |
| `mask_url` | 字符串（string） | 否（条件见下） | 未声明 | — | 局部重绘的蒙版地址；不能据此推断本站提供独立编辑路由。 |
| `model` | 字符串（string） | 必填 | 未声明 | 本节所选精确 model ID | 请求时原样填写本节列出的 ID；不同后缀是不同模型。 |
| `moderation` | 字符串（string） | 否（条件见下） | `auto` | 仅 `auto`、`low` | 内容审核档位；具体可用值见约束列。 |
| `n` | 整数（integer） | 否（条件见下） | `1` | 最小 1；最大 4 | 一次请求的生成数量；分层模型中不等于返回图层数。 |
| `nsfw_check` | 布尔（boolean） | 否（条件见下） | `false` | — | 内容安全检查参数；省略时仅在表中存在 default 才有已声明默认值。 |
| `output_compression` | 整数（integer） | 否（条件见下） | 未声明 | 最小 0；最大 100 | 压缩质量；只在支持的输出格式下传入。 |
| `output_format` | 字符串（string） | 否（条件见下） | `png` | 仅 `png`、`jpeg` | 生成文件的编码格式；与 response_format 不是同一参数。 |
| `prompt` | 字符串（string） | 必填 | 未声明 | — | 描述要生成的画面，或参考图需要如何修改。 |
| `quality` | 字符串（string） | 否（条件见下） | `auto` | 仅 `auto`、`low`、`medium`、`high` | 仅使用当前型号列出的质量枚举； |
| `size` | 字符串（string） | 否（条件见下） | `1:1` | 仅 `1:1`、`3:2`、`2:3` | 比例、像素值或尺寸档位的具体含义按本型号规则；不要套用其他型号。 |

### 条件必填、互斥与结构规则

- 根级必填：`model`、`prompt`。
- 当 必须提供 `mask_url` 时，必须提供 `image_urls`；`image_urls` 最少元素 1。
- 当 必须提供 `background`；`background` 固定 `transparent` 时，`output_format` 仅 `png`、`webp`。
