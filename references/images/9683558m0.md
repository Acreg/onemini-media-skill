# MiniMax H3 图片系列

> **Onemini 图片 API 参数参考。** API 地址：`https://api.onemini.top`。更新日期：2026-11-15。

## 调用前准备

先设置正式站 API Key（以下示例使用 Bash）：

```bash
export API_KEY="替换成正式站 API Key"
```

表格中“—”表示未公布枚举或上下限；“未声明”表示没有明确公布默认值。可选参数仍须满足对应模式的条件。

## 普通版与 Highspeed 分开使用

两个型号都是图片模型，不是同名 H3 视频模型。请使用带 `-image` 的精确 ID，并按各自表中的 `resolution`、`size`、`n`、参考图及输出格式约束提交。`prompt_optimizer`、`output_compression`、`watermark` 只按图片契约解释。

## 精确模型 ID

| model（原样填写） | 参数小节 | API 入口 |
| --- | --- | --- |
| `minimax-h3-image` | 本文第 1 组参数 | `POST /v1/images/generations` |
| `minimax-h3-image-highspeed` | 本文第 1 组参数 | `POST /v1/images/generations` |

## 响应与结果获取

提交接口为 `POST /v1/images/generations`。请求受理后返回 **HTTP 202**，任务号位于 `data.task_id`（也有 `data.id`）。任务号不是图片下载地址。

使用同一 API Key 调用 `GET /v1/media/tasks/{task_id}`；`data.status` 为 `succeeded` 后，普通图片的文件链接位于 `data.result.images[].url[]`。详细状态、轮询与停止流程见 [媒体任务查询、结果下载与请求停止](https://docs-api.onemini.top/9683548m0)。媒体任务号不使用 `/v1/images/tasks/{task_id}` 查询。

## 1. `minimax-h3-image` / `minimax-h3-image-highspeed`

本组 ID 共享下列字段结构与约束；`model` 应填写所选的完整 ID，不是任选版本后缀。

### 型号参数表

| 参数 | 类型 | 是否必填 | 默认值 | 枚举、范围与结构约束 | 中文说明 |
| --- | --- | --- | --- | --- | --- |
| `image_urls` | 数组<字符串（string）> | 否（条件见下） | 未声明 | 最多元素 16 | 文生图时省略；图生图或编辑时传入可读取的图片地址。 |
| `model` | 字符串（string） | 必填 | 未声明 | 本节所选精确 model ID | 请求时原样填写本节列出的 ID；不同后缀是不同模型。 |
| `n` | 整数（integer） | 否（条件见下） | `1` | 最小 1；最大 10 | 一次请求的生成数量；分层模型中不等于返回图层数。 |
| `nsfw_check` | 布尔（boolean） | 否（条件见下） | `false` | — | 内容安全检查参数；省略时仅在表中存在 default 才有已声明默认值。 |
| `output_compression` | 整数（integer） | 否（条件见下） | `95` | 最小 0；最大 100 | 压缩质量；只在支持的输出格式下传入。 |
| `output_format` | 字符串（string） | 否（条件见下） | `jpeg` | 仅 `jpeg`、`jpg`、`png`、`webp` | 生成文件的编码格式；与 response_format 不是同一参数。 |
| `prompt` | 字符串（string） | 必填 | 未声明 | 最少字符 1；最多字符 32000 | 描述要生成的画面，或参考图需要如何修改。 |
| `prompt_optimizer` | 布尔（boolean） | 否（条件见下） | `true` | — | 提示词优化；具体可用值见约束列。 |
| `resolution` | 字符串（string） | 否（条件见下） | `4K` | 仅 `1K`、`1k`、`2K`、`2k`、`4K`、`4k` | 原样传入表中大小写，不将 1K、1k、1MP 混为同一枚举。 |
| `size` | 字符串（string） | 否（条件见下） | `auto` | 满足至少一种：方案1 仅 `auto`、`1:1`、`4:3`、`16:9`、`9:16`、`3:1`、`1:3`；方案2 正则 `^(?:[1-9]&#124;[1-9][0-9]&#124;[12][0-9]{2}&#124;300):(?:[1-9]&#124;[1-9][0-9]&#124;[12][0-9]{2}&#124;300)$`；宽高比：≤3、≥0.3333333333333333；宽和高：≤300、≥1；方案3 正则 `^[1-9][0-9]{2,}[xX×*][1-9][0-9]{2,}$`；输出像素面积：≤20000000、≥655360；宽高比：≤3、≥0.3333333333333333 | 比例、像素值或尺寸档位的具体含义按本型号规则；不要套用其他型号。 支持自动构图、整数比例和精确像素；比例两项均为 1～300 的整数，宽高比须为 1:3～3:1。精确像素总面积为 655360～20000000，且不能同时设置分辨率；支持 x、X、×、* 分隔。省略分辨率时默认 4K。 |
| `watermark` | 布尔（boolean） | 否（条件见下） | `false` | — | 水印；具体可用值见约束列。 |

### 条件必填、互斥与结构规则

- 根级必填：`model`、`prompt`。
- 当 必须提供 `size`；`size` 正则 `^[0-9]+[xX×*][0-9]+$` 时，不得满足（至少满足一项：[必须提供 `resolution`]）。

### 本组基础调用示例

```bash
curl --request POST \
  --url "https://api.onemini.top/v1/images/generations" \
  --header "Authorization: Bearer ${API_KEY}" \
  --header "Content-Type: application/json" \
  --data-raw '{
  "model": "minimax-h3-image",
  "prompt": "一只橘猫坐在窗边，柔和自然光，画面简洁",
  "size": "auto",
  "resolution": "4K",
  "n": 1,
  "output_format": "jpeg"
}'
```

调用本组其他型号时，只需把示例 `model` 换成上面同组的精确 ID；不要改成文档标题或自行删除后缀。
