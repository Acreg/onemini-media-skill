# GPT Image 2.5 / 2.6：生成、编辑、GIF 与 SVG

> **Onemini 图片 API 参数参考。** API 地址：`https://api.onemini.top`。更新日期：2026-11-15。

## 调用前准备

先设置正式站 API Key（以下示例使用 Bash）：

```bash
export API_KEY="替换成正式站 API Key"
```

表格中“—”表示未公布枚举或上下限；“未声明”表示没有明确公布默认值。可选参数仍须满足对应模式的条件。

## 三种后缀不是同一份参数

- `-flare`、`-sunburst` 用精确 ID 选择版本；`-ext` 则使用 `version` 选择 `flare` / `sunburst`。
- 2.5 Flare/Sunburst 的 `resolution` 为小写 `1k/2k/4k`；2.5 Ext 为大写 `1K/2K/4K`；2.6 Ext 同时列出大小写，不能由此推断所有系列都忽略大小写。
- 2.6 的 `output_format` 才明确列出 `gif`、`svg`；2.5 不继承这两个格式。2.6 Ext 固定 `n=1`；2.5 Ext 可 `n=1～4`。
- Flare/Sunburst 与 Ext 的计量方式可能不同，本站费用以当前账户与型号价格为准，不照搬上游采购价、退款承诺或计费公式。

## 精确模型 ID

| model（原样填写） | 参数小节 | API 入口 |
| --- | --- | --- |
| `gpt-image-2.5-flare` | 本文第 1 组参数 | `POST /v1/images/generations` |
| `gpt-image-2.5-sunburst` | 本文第 1 组参数 | `POST /v1/images/generations` |
| `gpt-image-2.5-ext` | 本文第 2 组参数 | `POST /v1/images/generations` |
| `gpt-image-2.6-flare` | 本文第 3 组参数 | `POST /v1/images/generations` |
| `gpt-image-2.6-sunburst` | 本文第 3 组参数 | `POST /v1/images/generations` |
| `gpt-image-2.6-ext` | 本文第 4 组参数 | `POST /v1/images/generations` |

## 响应与结果获取

提交接口为 `POST /v1/images/generations`。请求受理后返回 **HTTP 202**，任务号位于 `data.task_id`（也有 `data.id`）。任务号不是图片下载地址。

使用同一 API Key 调用 `GET /v1/media/tasks/{task_id}`；`data.status` 为 `succeeded` 后，普通图片的文件链接位于 `data.result.images[].url[]`。详细状态、轮询与停止流程见 [媒体任务查询、结果下载与请求停止](https://docs-api.onemini.top/9683548m0)。媒体任务号不使用 `/v1/images/tasks/{task_id}` 查询。

## 1. `gpt-image-2.5-flare` / `gpt-image-2.5-sunburst`

本组 ID 共享下列字段结构与约束；`model` 应填写所选的完整 ID，不是任选版本后缀。

### 型号参数表

| 参数 | 类型 | 是否必填 | 默认值 | 枚举、范围与结构约束 | 中文说明 |
| --- | --- | --- | --- | --- | --- |
| `background` | 字符串（string） | 否（条件见下） | 未声明 | 仅 `transparent`、`opaque`、`auto` | 背景方式；具体可用值见约束列。 |
| `image_urls` | 数组<字符串（string）> | 否（条件见下） | 未声明 | 最多元素 16 | 文生图时省略；图生图或编辑时传入可读取的图片地址。 |
| `mask_url` | 字符串（string） | 否（条件见下） | 未声明 | — | 局部重绘的蒙版地址；不能据此推断本站提供独立编辑路由。 |
| `model` | 字符串（string） | 必填 | 未声明 | 本节所选精确 model ID | 请求时原样填写本节列出的 ID；不同后缀是不同模型。 |

| `n` | 整数（integer） | 否（条件见下） | `1` | 最小 1；最大 4 | 一次请求的生成数量；分层模型中不等于返回图层数。 |
| `nsfw_check` | 布尔（boolean） | 否（条件见下） | `false` | — | 内容安全检查参数；省略时仅在表中存在 default 才有已声明默认值。 |
| `output_compression` | 整数（integer） | 否（条件见下） | 未声明 | 最小 0；最大 100 | 压缩质量；只在支持的输出格式下传入。 |

| `size` | 字符串（string） | 否（条件见下） | `auto` | 正则 `^(auto&#124;1:1&#124;2:3&#124;3:2&#124;3:4&#124;4:3&#124;4:5&#124;5:4&#124;9:16&#124;16:9&#124;21:9&#124;2:1&#124;1:2&#124;3:1&#124;1:3&#124;9:21&#124;[1-9][0-9]*[xX][1-9][0-9]*)$` | 比例、像素值或尺寸档位的具体含义按本型号规则；不要套用其他型号。 |

### 条件必填、互斥与结构规则

- 根级必填：`model`、`prompt`。

- 当 必须提供 `background`；`background` 固定 `transparent` 时，`output_format` 仅 `png`、`webp`。

## 3. `gpt-image-2.6-flare` / `gpt-image-2.6-sunburst`

**gpt-image-2.6-flare：** SVG 输出必须提供 svg 对象，且对象内 model 必填，n 必须为 1；同时禁止 mask_url、markup_url、markup 和 output_compression。透明背景仅 png/webp；显式 output_compression 仅 jpeg/webp。GIF 的GIF 另有运行限制，下面示例仅用 n=1、size=auto。

**gpt-image-2.6-sunburst：** 与本节 Flare 同一输入契约；SVG 必须带 svg.model 且 n=1。GIF 不套用普通静态图 n 上限。

| `model` | 字符串（string） | 必填 | 未声明 | 固定 `gpt-image-2.6-ext` | 请求时原样填写本节列出的 ID；不同后缀是不同模型。 |
| `n` | 整数（integer） | 否（条件见下） | `1` | 固定 `1` | 一次请求的生成数量；分层模型中不等于返回图层数。 |
| `nsfw_check` | 布尔（boolean） | 否（条件见下） | `false` | — | 内容安全检查参数；省略时仅在表中存在 default 才有已声明默认值。 |
| `output_format` | 字符串（string） | 否（条件见下） | `png` | 仅 `png`、`jpeg`、`webp`、`gif`、`svg`、`jpg` | 生成文件的编码格式；与 response_format 不是同一参数。 |
| `prompt` | 字符串（string） | 必填 | 未声明 | — | 描述要生成的画面，或参考图需要如何修改。 |
| `quality` | 字符串（string） | 否（条件见下） | 未声明 | 仅 `auto`、`low`、`medium`、`high`、`xhigh`、`max` | 仅使用当前型号列出的质量枚举； |
| `resolution` | 字符串（string） | 否（条件见下） | `1k` | 仅 `1k`、`1K`、`2k`、`2K`、`4k`、`4K` | 原样传入表中大小写，不将 1K、1k、1MP 混为同一枚举。 |
| `size` | 字符串（string） | 否（条件见下） | `auto` | 仅 `auto`、`1:1`、`2:3`、`3:2`、`3:4`、`4:3`、`4:5`、`5:4`、`9:16`、`16:9`、`21:9` | 比例、像素值或尺寸档位的具体含义按本型号规则；不要套用其他型号。 |
| `svg` | 对象（object） | 否（条件见下） | 未声明 | — | SVG 专用配置；其子字段是否必填见条件规则。不要把示例模型名当作本站可用编写模型。 |
| `svg.model` | 字符串（string） | 父对象出现时必填 | 未声明 | 最少字符 1 | 请求时原样填写本节列出的 ID；不同后缀是不同模型。 |
| `svg.reasoning` | 对象（object） | 否（条件见下） | 未声明 | — | 推理配置；具体可用值见约束列。 |
| `svg.reasoning.effort` | 字符串 / null | 否（条件见下） | 未声明 | 正则 `^([Nn][Oo][Nn][Ee]&#124;[Mm][Ii][Nn][Ii][Mm][Aa][Ll]&#124;[Ll][Oo][Ww]&#124;[Mm][Ee][Dd][Ii][Uu][Mm]&#124;[Hh][Ii][Gg][Hh]&#124;[Xx][Hh][Ii][Gg][Hh]&#124;[Mm][Aa][Xx])$` | 推理强度仅按列出的格式校验，不转为图片 quality 参数。 |
| `version` | 字符串（string） | 否（条件见下） | `flare` | 仅 `flare`、`sunburst` | 模型版本；具体可用值见约束列。 |

### 条件必填、互斥与结构规则

- 根级必填：`model`、`prompt`。
- 当 必须提供 `output_format`；`output_format` 仅 `gif`、`svg` 时，不得满足（至少满足一项：[必须提供 `image_urls`]）。

### 2.5 Flare 使用参考图

先在 shell 中设置以下环境变量：

- `REFERENCE_IMAGE_URL`：自己可直接访问的参考图片地址。

```bash
curl --request POST \
  --url "https://api.onemini.top/v1/images/generations" \
  --header "Authorization: Bearer ${API_KEY}" \
  --header "Content-Type: application/json" \
  --data-binary @- <<JSON
{
  "model": "gpt-image-2.5-flare",
  "prompt": "保留参考图主体与构图，改成柔和水彩风格",
  "resolution": "1k",
  "size": "auto",
  "n": 1,
  "image_urls": [
    "${REFERENCE_IMAGE_URL}"
  ]
}
JSON
```

SVG 的 `svg.model`、图片模型 `model`、画面 `complexity`、图片 `quality` 是不同参数，不可互相替代。结果仍查询同一媒体任务，并从结果中取得对应文件链接。
