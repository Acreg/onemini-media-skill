# Seedream：文生图、参考图、透明背景与分层

> **Onemini 图片 API 参数参考。** API 地址：`https://api.onemini.top`。更新日期：2026-11-15。

## 调用前准备

先设置正式站 API Key（以下示例使用 Bash）：

```bash
export API_KEY="替换成正式站 API Key"
```

表格中“—”表示未公布枚举或上下限；“未声明”表示没有明确公布默认值。可选参数仍须满足对应模式的条件。

## 普通生成、连续组图与分层是三种模式

- 4.0、4.5、5.0 Lite 支持 `sequential_image_generation` 和 `sequential_image_generation_options.max_images`，普通 `n` 上限为 15。
- 4.0 的 `optimize_prompt_options` 是字符串；4.5 / 5.0 Pro / 5.0 Flash / 5.5 使用对象，不能互换。5.0 Lite 没有确认此字段。
- 5.0 Pro、5.0 Flash、5.5 使用 `layer_decomposition` 做拆层，且 `n=1`；返回多层不意味着请求 `n` 可以大于 1。
- 5.5 的 `layer_decomposition_options.max_images` 为 2～100，默认 30，**包含底图**。5.0 Pro/Flash 的契约没有该设置，不要套用。
- 5.0 Pro/Flash 透明背景必须恰好 1 张参考图并明确 `output_format:"png"`；5.5 的透明背景规则不同，见本型号条件。

## 精确模型 ID

| model（原样填写） | 参数小节 | API 入口 |
| --- | --- | --- |
| `seedream-4-0` | 本文第 1 组参数 | `POST /v1/images/generations` |
| `seedream-4-5` | 本文第 2 组参数 | `POST /v1/images/generations` |
| `seedream-5-0-flash` | 本文第 3 组参数 | `POST /v1/images/generations` |
| `seedream-5-0-pro` | 本文第 3 组参数 | `POST /v1/images/generations` |
| `seedream-5-0-lite` | 本文第 4 组参数 | `POST /v1/images/generations` |
| `seedream-5-5` | 本文第 5 组参数 | `POST /v1/images/generations` |

## 响应与结果获取

提交接口为 `POST /v1/images/generations`。请求受理后返回 **HTTP 202**，任务号位于 `data.task_id`（也有 `data.id`）。任务号不是图片下载地址。

使用同一 API Key 调用 `GET /v1/media/tasks/{task_id}`；`data.status` 为 `succeeded` 后，普通图片的文件链接位于 `data.result.images[].url[]`。详细状态、轮询与停止流程见 [媒体任务查询、结果下载与请求停止](https://docs-api.onemini.top/9683548m0)。媒体任务号不使用 `/v1/images/tasks/{task_id}` 查询。

## 1. `seedream-4-0`

本组 ID 共享下列字段结构与约束；`model` 应填写所选的完整 ID，不是任选版本后缀。

### 型号参数表

| 参数 | 类型 | 是否必填 | 默认值 | 枚举、范围与结构约束 | 中文说明 |
| --- | --- | --- | --- | --- | --- |
| `image_urls` | 数组<字符串（string）> | 否（条件见下） | 未声明 | — | 文生图时省略；图生图或编辑时传入可读取的图片地址。 |
| `model` | 字符串（string） | 必填 | 未声明 | 固定 `seedream-4-0` | 请求时原样填写本节列出的 ID；不同后缀是不同模型。 |
| `n` | 整数（integer） | 否（条件见下） | `1` | 最小 1；最大 15 | 一次请求的生成数量；分层模型中不等于返回图层数。 |
| `nsfw_check` | 布尔（boolean） | 否（条件见下） | `false` | — | 内容安全检查参数；省略时仅在表中存在 default 才有已声明默认值。 |
| `optimize_prompt_options` | 字符串（string） | 否（条件见下） | `standard` | 仅 `standard`、`fast` | 提示词优化设置；具体可用值见约束列。 |
| `prompt` | 字符串（string） | 必填 | 未声明 | 最多字符 1000 | 描述要生成的画面，或参考图需要如何修改。 |
| `resolution` | 字符串（string） | 否（条件见下） | `2K` | 仅 `1K`、`2K`、`4K` | 原样传入表中大小写，不将 1K、1k、1MP 混为同一枚举。 |
| `sequential_image_generation` | 字符串（string） | 否（条件见下） | `disabled` | 仅 `disabled`、`auto` | 连续组图模式；具体可用值见约束列。 |
| `sequential_image_generation_options` | 对象（object） | 否（条件见下） | 未声明 | — | 连续组图设置；具体可用值见约束列。 |
| `sequential_image_generation_options.max_images` | 整数（integer） | 否（条件见下） | 未声明 | 最小 1；最大 15 | 最大结果数；Seedream 5.5 分层时包含底图，不是额外图层数。 |
| `size` | 字符串（string） | 否（条件见下） | `1:1` | 仅 `1:1`、`4:3`、`3:4`、`16:9`、`9:16`、`3:2`、`2:3`、`2:1`、`1:2`、`21:9`、`9:21`、`auto`、`2x1`、`1x2` | 比例、像素值或尺寸档位的具体含义按本型号规则；不要套用其他型号。 |
| `watermark` | 布尔（boolean） | 否（条件见下） | `false` | — | 水印；具体可用值见约束列。 |

### 条件必填、互斥与结构规则

- 根级必填：`model`、`prompt`。
- 当 必须提供 `size`；`size` 固定 `auto` 时，必须提供 `image_urls`；`image_urls` 最少元素 1。

## 3. `seedream-5-0-flash` / `seedream-5-0-pro`

本组 ID 共享下列字段结构与约束；`model` 应填写所选的完整 ID，不是任选版本后缀。

**seedream-5-0-flash：** 分层模式使用与 Pro 相同的专门适配分支，要求 n=1、恰好 1 张参考图、层尺寸为 1K/1.5K/2K/auto；普通模式按本节生成规则。

**seedream-5-0-pro：** 普通模式必须有非空 prompt；分层模式可以省略 prompt，但恰好需要 1 张参考图。分层 size 只能 1K/1.5K/2K/auto，不接受比例或精确像素。适配器会将档位大小写正规化，并补 n=1 和 resolution；client_ref 在转发前删除。

### 型号参数表

| 参数 | 类型 | 是否必填 | 默认值 | 枚举、范围与结构约束 | 中文说明 |
| --- | --- | --- | --- | --- | --- |
| `background` | 字符串（string） | 否（条件见下） | `opaque` | 仅 `opaque`、`transparent` | 背景方式；具体可用值见约束列。 |
| `image_urls` | 数组<字符串（string）> | 否（条件见下） | 未声明 | 最多元素 10 | 文生图时省略；图生图或编辑时传入可读取的图片地址。 |
| `layer_decomposition` | 布尔（boolean） | 否（条件见下） | `false` | — | 开启后走图片拆层而非普通生成；来源图片、提示词和背景限制随型号改变。 |
| `model` | 字符串（string） | 必填 | 未声明 | 本节所选精确 model ID | 请求时原样填写本节列出的 ID；不同后缀是不同模型。 |
| `n` | 整数（integer） | 否（条件见下） | `1` | 固定 `1` | 一次请求的生成数量；分层模型中不等于返回图层数。 |
| `nsfw_check` | 布尔（boolean） | 否（条件见下） | `false` | — | 内容安全检查参数；省略时仅在表中存在 default 才有已声明默认值。 |
| `optimize_prompt_options` | 对象（object） | 否（条件见下） | 未声明 | — | 提示词优化设置；具体可用值见约束列。 |
| `optimize_prompt_options.mode` | 字符串（string） | 否（条件见下） | `standard` | 固定 `standard` | 模式；具体可用值见约束列。 |
| `output_format` | 字符串（string） | 否（条件见下） | `jpeg` | 仅 `jpeg`、`png` | 生成文件的编码格式；与 response_format 不是同一参数。 |
| `prompt` | 字符串（string） | 否（条件见下） | 未声明 | — | 描述要生成的画面，或参考图需要如何修改。 |
| `resolution` | 字符串（string） | 否（条件见下） | `1K` | 仅 `1K`、`1k`、`1.5K`、`1.5k`、`2K`、`2k` | 原样传入表中大小写，不将 1K、1k、1MP 混为同一枚举。 |
| `size` | 字符串（string） | 否（条件见下） | `auto` | 满足至少一种：方案1 仅 `auto`、`1K`、`1k`、`1.5K`、`1.5k`、`2K`、`2k`；方案2 仅 `1:1`、`4:3`、`3:4`、`16:9`、`9:16`、`3:2`、`2:3`、`2:1`、`1:2`、`21:9`；方案3 仅 `1x1`、`4x3`、`3x4`、`16x9`、`9x16`、`3x2`、`2x3`、`2x1`、`1x2`、`21x9`；方案4 正则 `^[1-9][0-9]{2,}[xX×][1-9][0-9]{2,}$`；输出像素面积：≤4624220、≥921600；宽高比：≤16、≥0.0625 | 比例、像素值或尺寸档位的具体含义按本型号规则；不要套用其他型号。 支持自动、1K／1.5K／2K 档位、所列比例及精确像素；精确像素的总面积须为 921600～4624220，宽高比为 1:16～16:1。比例可用小写 x 分隔。分层输出仅接受自动或档位。尺寸为档位时优先于分辨率；精确像素时分辨率不生效。 |
| `watermark` | 布尔（boolean） | 否（条件见下） | `false` | — | 水印；具体可用值见约束列。 |

### 条件必填、互斥与结构规则

- 根级必填：`model`。
- 至少满足一项：[必须提供 `prompt`] 或 [必须提供 `image_urls`]。
- 当 必须提供 `layer_decomposition`；`layer_decomposition` 固定 `true` 时，必须提供 `image_urls`；`image_urls` 最少元素 1；最多元素 1；否则 必须提供 `prompt`。
- 当 必须提供 `background`；`background` 固定 `transparent` 时，必须提供 `image_urls`、`output_format`；`image_urls` 最少元素 1；最多元素 1；`output_format` 固定 `png`。
- 当 必须提供 `layer_decomposition`；`layer_decomposition` 固定 `true` 时，`size` 仅 `1K`、`1k`、`1.5K`、`1.5k`、`2K`、`2k`、`auto`。

## 5. `seedream-5-5`

本组 ID 共享下列字段结构与约束；`model` 应填写所选的完整 ID，不是任选版本后缀。

**seedream-5-5：** 适配器不支持 `sequential_image_generation`、`stream`、`tools`。普通模式必须非空 prompt；分层可以省略 prompt，必须恰好 1 张参考图，禁止 background；layer_decomposition_options 仅在分层模式可传。透明背景不接受 JPEG；请显式 output_format=png。普通请求省略尺寸时按 2K 预留。
