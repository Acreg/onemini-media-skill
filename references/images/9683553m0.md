# Flux：Kontext、2 系列与 3 系列

> **Onemini 图片 API 参数参考。** API 地址：`https://api.onemini.top`。更新日期：2026-11-15。

## 调用前准备

先设置正式站 API Key（以下示例使用 Bash）：

```bash
export API_KEY="替换成正式站 API Key"
```

表格中“—”表示未公布枚举或上下限；“未声明”表示没有明确公布默认值。可选参数仍须满足对应模式的条件。

## 模型族之间不能混用参数

- Kontext Pro/Max 使用 `size`，固定 `n=1`，参考图最多 4 张，支持本型号的 `response_format`。
- Flux 2 Flex/Pro/Max 支持最多 8 张参考图以及成对 `width` / `height`。**只有 Flex 支持 `steps` 和 `guidance`，Pro/Max 必须省略这两个参数。**
- Flux 2 的 `resolution` 使用 MP 档位及其明确别名，不是所有型号通用的 `1k/2k/4k`。精确尺寸的面积限制见参数表。
- Flux 3 Image 与 Flux 3 Klein 的分辨率、参考图、种子和格式约束分别列出；不要因为同属 Flux 就合并。

## 精确模型 ID

| model（原样填写） | 参数小节 | API 入口 |
| --- | --- | --- |
| `flux-2-flex` | 本文第 1 组参数 | `POST /v1/images/generations` |
| `flux-2-max` | 本文第 2 组参数 | `POST /v1/images/generations` |
| `flux-2-pro` | 本文第 2 组参数 | `POST /v1/images/generations` |
| `flux-3-image` | 本文第 3 组参数 | `POST /v1/images/generations` |
| `flux-3-image-klein` | 本文第 4 组参数 | `POST /v1/images/generations` |
| `flux-kontext-max` | 本文第 5 组参数 | `POST /v1/images/generations` |
| `flux-kontext-pro` | 本文第 5 组参数 | `POST /v1/images/generations` |

## 响应与结果获取

提交接口为 `POST /v1/images/generations`。请求受理后返回 **HTTP 202**，任务号位于 `data.task_id`（也有 `data.id`）。任务号不是图片下载地址。

使用同一 API Key 调用 `GET /v1/media/tasks/{task_id}`；`data.status` 为 `succeeded` 后，普通图片的文件链接位于 `data.result.images[].url[]`。详细状态、轮询与停止流程见 [媒体任务查询、结果下载与请求停止](https://docs-api.onemini.top/9683548m0)。媒体任务号不使用 `/v1/images/tasks/{task_id}` 查询。

## 1. `flux-2-flex`

本组 ID 共享下列字段结构与约束；`model` 应填写所选的完整 ID，不是任选版本后缀。

**flux-2-flex：** 自定义 size 的输出面积≤4194304；含参考图总面积≤9437184 由上游按真实图片尺寸确认。不要只用正则判定任意超长宽高都有效。

### 型号参数表

| 参数 | 类型 | 是否必填 | 默认值 | 枚举、范围与结构约束 | 中文说明 |
| --- | --- | --- | --- | --- | --- |
| `guidance` | 数值（number） | 否（条件见下） | `5` | 最小 1.5；最大 10 | 引导强度；具体可用值见约束列。 |
| `height` | 整数（integer） | 否（条件见下） | 未声明 | 最小 64 | 像素高度；要求完整宽高成对提供的型号见条件规则。 |
| `image_urls` | 数组<字符串（string）> | 否（条件见下） | 未声明 | 最多元素 8 | 文生图时省略；图生图或编辑时传入可读取的图片地址。 |
| `model` | 字符串（string） | 必填 | 未声明 | 固定 `flux-2-flex` | 请求时原样填写本节列出的 ID；不同后缀是不同模型。 |
| `n` | 整数（integer） | 否（条件见下） | `1` | 固定 `1` | 一次请求的生成数量；分层模型中不等于返回图层数。 |
| `nsfw_check` | 布尔（boolean） | 否（条件见下） | `false` | — | 内容安全检查参数；省略时仅在表中存在 default 才有已声明默认值。 |
| `output_format` | 字符串（string） | 否（条件见下） | `jpeg` | 仅 `jpeg`、`png`、`webp` | 生成文件的编码格式；与 response_format 不是同一参数。 |
| `prompt` | 字符串（string） | 必填 | 未声明 | — | 描述要生成的画面，或参考图需要如何修改。 |
| `prompt_upsampling` | 布尔（boolean） | 否（条件见下） | `false` | — | 提示词增强开关。 |
| `resolution` | 字符串（string） | 否（条件见下） | `2MP` | 仅 `1MP`、`2MP`、`3MP`、`4MP`、`512`、`512P`、`1M`、`1K`、`1024`、`2K`、`2048`、`4K` | 原样传入表中大小写，不将 1K、1k、1MP 混为同一枚举。 |
| `safety_tolerance` | 整数（integer） | 否（条件见下） | `2` | 最小 0；最大 5 | 安全容忍度；具体可用值见约束列。 |
| `seed` | 整数（integer） | 否（条件见下） | 未声明 | — | 随机种子；不额外承诺跨版本或跨渠道的逐像素复现。 |
| `size` | 字符串（string） | 否（条件见下） | `1:1` | 满足至少一种：方案1 仅 `1:1`、`4:3`、`3:4`、`16:9`、`9:16`、`3:2`、`2:3`、`21:9`、`9:21`、`auto`；方案2 正则 `^(?:6[4-9]&#124;[7-9][0-9]&#124;[1-9][0-9]{2,})x(?:6[4-9]&#124;[7-9][0-9]&#124;[1-9][0-9]{2,})$`；输出像素面积：≤4194304；高度：≥64；含参考图的总像素面积（交由上游校验）：≤9437184；宽度：≥64 | 比例、像素值或尺寸档位的具体含义按本型号规则；不要套用其他型号。 默认 1:1；自动模式有参考图时跟随参考图，无参考图时为 1:1。精确像素每边至少 64，总面积不超过 4194304；输出与所有参考图总面积不超过 9437184。完整宽高参数优先于尺寸，精确像素尺寸优先于分辨率档位。 |
| `steps` | 整数（integer） | 否（条件见下） | `50` | 最小 1；最大 50 | 采样步数；具体可用值见约束列。 |
| `width` | 整数（integer） | 否（条件见下） | 未声明 | 最小 64 | 像素宽度；要求完整宽高成对提供的型号见条件规则。 |

### 条件必填、互斥与结构规则

- 根级必填：`model`、`prompt`。
- 当 必须提供 `width` 时，必须提供 `height`。
- 当 必须提供 `height` 时，必须提供 `width`。
