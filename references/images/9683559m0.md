# Imagen、混元、MAI 与 Muse 图片模型

> **Onemini 图片 API 参数参考。** API 地址：`https://api.onemini.top`。更新日期：2026-11-15。

## 调用前准备

先设置正式站 API Key（以下示例使用 Bash）：

```bash
export API_KEY="替换成正式站 API Key"
```

表格中“—”表示未公布枚举或上下限；“未声明”表示没有明确公布默认值。可选参数仍须满足对应模式的条件。

## 四个独立模型族

- Imagen 4.0 为 `imagen-4.0-apimart`，固定 `n=1`，不提供本页所述的参考图输入方式。
- 混元 `hy-image-v3.5-preview` 支持成对宽高、最多 5 张参考图、种子和负面提示词。像素每边 256～8192，面积≤8294400，建议 16 的倍数。
- MAI 2.6 与 Flash 支持 `auto_aspect_ratio`、`web_grounding`，成对宽高至少 768；精确像素尺寸面积≤2359296，每边向下取整到 32 的倍数。参考图编辑时由模型决定输出尺寸，不保证所填像素就是最终输出像素。
- Muse 使用自己的 `language`、`aspect_ratio` 等字段，不继承混元或 MAI 的设置。

## 精确模型 ID

| model（原样填写） | 参数小节 | API 入口 |
| --- | --- | --- |
| `imagen-4.0-apimart` | 本文第 1 组参数 | `POST /v1/images/generations` |
| `hy-image-v3.5-preview` | 本文第 2 组参数 | `POST /v1/images/generations` |
| `mai-image-2.6` | 本文第 3 组参数 | `POST /v1/images/generations` |
| `mai-image-2.6-flash` | 本文第 3 组参数 | `POST /v1/images/generations` |
| `muse-image-ext` | 本文第 4 组参数 | `POST /v1/images/generations` |

## 响应与结果获取

提交接口为 `POST /v1/images/generations`。请求受理后返回 **HTTP 202**，任务号位于 `data.task_id`（也有 `data.id`）。任务号不是图片下载地址。

使用同一 API Key 调用 `GET /v1/media/tasks/{task_id}`；`data.status` 为 `succeeded` 后，普通图片的文件链接位于 `data.result.images[].url[]`。详细状态、轮询与停止流程见 [媒体任务查询、结果下载与请求停止](https://docs-api.onemini.top/9683548m0)。媒体任务号不使用 `/v1/images/tasks/{task_id}` 查询。

## 1. `imagen-4.0-apimart`

本组 ID 共享下列字段结构与约束；`model` 应填写所选的完整 ID，不是任选版本后缀。

### 型号参数表

| 参数 | 类型 | 是否必填 | 默认值 | 枚举、范围与结构约束 | 中文说明 |
| --- | --- | --- | --- | --- | --- |
| `model` | 字符串（string） | 必填 | 未声明 | 固定 `imagen-4.0-apimart` | 请求时原样填写本节列出的 ID；不同后缀是不同模型。 |
| `n` | 整数（integer） | 否（条件见下） | `1` | 固定 `1` | 一次请求的生成数量；分层模型中不等于返回图层数。 |
| `nsfw_check` | 布尔（boolean） | 否（条件见下） | `false` | — | 内容安全检查参数；省略时仅在表中存在 default 才有已声明默认值。 |
| `prompt` | 字符串（string） | 必填 | 未声明 | — | 描述要生成的画面，或参考图需要如何修改。 |
| `size` | 字符串（string） | 否（条件见下） | `16:9` | 仅 `1:1`、`4:3`、`3:4`、`16:9`、`9:16` | 比例、像素值或尺寸档位的具体含义按本型号规则；不要套用其他型号。 |

### 条件必填、互斥与结构规则

- 根级必填：`model`、`prompt`。


### 本组基础调用示例

```bash
curl --request POST \
  --url "https://api.onemini.top/v1/images/generations" \
  --header "Authorization: Bearer ${API_KEY}" \
  --header "Content-Type: application/json" \
  --data-raw '{
  "model": "imagen-4.0-apimart",
  "prompt": "一只橘猫坐在窗边，柔和自然光，画面简洁",
  "size": "16:9",
  "n": 1
}'
```
