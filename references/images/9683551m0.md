# Gemini 与 Nano Banana 图片模型

> **Onemini 图片 API 参数参考。** API 地址：`https://api.onemini.top`。更新日期：2026-11-15。

## 调用前准备

先设置正式站 API Key（以下示例使用 Bash）：

```bash
export API_KEY="替换成正式站 API Key"
```

表格中“—”表示未公布枚举或上下限；“未声明”表示没有明确公布默认值。可选参数仍须满足对应模式的条件。

## Nano Banana 与 Gemini 的差别

- `gemini-nano-banana-2.1` 的 `n` 为 1～4，`gemini-nano-banana-2.1-ext` 固定为 1。
- Gemini 3.1 Flash Preview 有 `google_search` 和 `google_image_search`；不要给所有 Gemini 图片模型加这两个字段。
- 3.1 Flash Preview 的分辨率包含 `0.5K`；3.1 Flash Lite 仅 `1K`；3 Pro 为 `1K/2K/4K`；2.5 Flash 仅 `1K`。
- 型号中的 `-official` 是精确 ID 的一部分，并不意味着应改用 Google 原生 `generateContent` 参数。本文只说明图片 API 调用，不将同名原生 Google 或聊天适配协议混为一谈。

## 响应与结果获取

提交接口为 `POST /v1/images/generations`。请求受理后返回 **HTTP 202**，任务号位于 `data.task_id`（也有 `data.id`）。任务号不是图片下载地址。

使用同一 API Key 调用 `GET /v1/media/tasks/{task_id}`；`data.status` 为 `succeeded` 后，普通图片的文件链接位于 `data.result.images[].url[]`。详细状态、轮询与停止流程见 [媒体任务查询、结果下载与请求停止](https://docs-api.onemini.top/9683548m0)。媒体任务号不使用 `/v1/images/tasks/{task_id}` 查询。

## 1. `gemini-2.5-flash-image-preview`

本组 ID 共享下列字段结构与约束；`model` 应填写所选的完整 ID，不是任选版本后缀。

### 型号参数表

| 参数 | 类型 | 是否必填 | 默认值 | 枚举、范围与结构约束 | 中文说明 |
| --- | --- | --- | --- | --- | --- |
| `image_urls` | 数组<字符串（string）> | 否（条件见下） | 未声明 | — | 文生图时省略；图生图或编辑时传入可读取的图片地址。 |
| `model` | 字符串（string） | 必填 | 未声明 | 固定 `gemini-2.5-flash-image-preview` | 请求时原样填写本节列出的 ID；不同后缀是不同模型。 |
| `n` | 整数（integer） | 否（条件见下） | `1` | 固定 `1` | 一次请求的生成数量；分层模型中不等于返回图层数。 |
| `nsfw_check` | 布尔（boolean） | 否（条件见下） | `false` | — | 内容安全检查参数；省略时仅在表中存在 default 才有已声明默认值。 |
| `official_fallback` | 布尔（boolean） | 否（条件见下） | `false` | — | 是否允许上游按该型号的回退机制处理；不等于切换为本站原生协议。 |
| `prompt` | 字符串（string） | 必填 | 未声明 | 最多字符 1000 | 描述要生成的画面，或参考图需要如何修改。 |
| `resolution` | 字符串（string） | 否（条件见下） | `1K` | 仅 `1K` | 原样传入表中大小写，不将 1K、1k、1MP 混为同一枚举。 |
| `size` | 字符串（string） | 否（条件见下） | 未声明 | 仅 `auto`、`1:1`、`2:3`、`3:2`、`3:4`、`4:3`、`4:5`、`5:4`、`9:16`、`16:9`、`21:9` | 比例、像素值或尺寸档位的具体含义按本型号规则；不要套用其他型号。 |

### 条件必填、互斥与结构规则

- 根级必填：`model`、`prompt`。


### 本组基础调用示例

```bash
curl --request POST \
  --url "https://api.onemini.top/v1/images/generations" \
  --header "Authorization: Bearer ${API_KEY}" \
  --header "Content-Type: application/json" \
  --data-raw '{
  "model": "gemini-2.5-flash-image-preview",
  "prompt": "一只橘猫坐在窗边，柔和自然光，画面简洁",
  "resolution": "1K",
  "n": 1
}'
```
