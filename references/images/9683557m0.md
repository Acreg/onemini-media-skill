# Qwen Image 与 Z Image

> **Onemini 图片 API 参数参考。** API 地址：`https://api.onemini.top`。更新日期：2026-11-15。

## 调用前准备

先设置正式站 API Key（以下示例使用 Bash）：

```bash
export API_KEY="替换成正式站 API Key"
```

表格中“—”表示未公布枚举或上下限；“未声明”表示没有明确公布默认值。可选参数仍须满足对应模式的条件。

## Qwen 2.0、3.0 与 Z Image

Qwen 3.0 / 3.0 Pro 增加 `prompt_extend`、`prompt_extend_mode`，不要套给 2.0 系列。`z-image-turbo` 的参数仅有提示词、尺寸/分辨率、提示词扩展与内容检查；本页不提供图生图调用。

## 精确模型 ID

| model（原样填写） | 参数小节 | API 入口 |
| --- | --- | --- |
| `qwen-image-2.0` | 本文第 1 组参数 | `POST /v1/images/generations` |
| `qwen-image-2.0-pro` | 本文第 1 组参数 | `POST /v1/images/generations` |
| `qwen-image-3.0` | 本文第 2 组参数 | `POST /v1/images/generations` |
| `qwen-image-3.0-pro` | 本文第 2 组参数 | `POST /v1/images/generations` |
| `z-image-turbo` | 本文第 3 组参数 | `POST /v1/images/generations` |

## 响应与结果获取

提交接口为 `POST /v1/images/generations`。请求受理后返回 **HTTP 202**，任务号位于 `data.task_id`（也有 `data.id`）。任务号不是图片下载地址。

使用同一 API Key 调用 `GET /v1/media/tasks/{task_id}`；`data.status` 为 `succeeded` 后，普通图片的文件链接位于 `data.result.images[].url[]`。详细状态、轮询与停止流程见 [媒体任务查询、结果下载与请求停止](https://docs-api.onemini.top/9683548m0)。媒体任务号不使用 `/v1/images/tasks/{task_id}` 查询。

## 1. `qwen-image-2.0` / `qwen-image-2.0-pro`

本组 ID 共享下列字段结构与约束；`model` 应填写所选的完整 ID，不是任选版本后缀。

### 型号参数表

| 参数 | 类型 | 是否必填 | 默认值 | 枚举、范围与结构约束 | 中文说明 |
| --- | --- | --- | --- | --- | --- |
| `image_urls` | 数组<字符串（string）> | 否（条件见下） | 未声明 | — | 文生图时省略；图生图或编辑时传入可读取的图片地址。 |
| `model` | 字符串（string） | 必填 | 未声明 | 本节所选精确 model ID | 请求时原样填写本节列出的 ID；不同后缀是不同模型。 |
| `n` | 整数（integer） | 否（条件见下） | `1` | 最小 1；最大 6 | 一次请求的生成数量；分层模型中不等于返回图层数。 |
| `negative_prompt` | 字符串（string） | 否（条件见下） | 未声明 | 最多字符 500 | 负面提示词；具体可用值见约束列。 |
| `nsfw_check` | 布尔（boolean） | 否（条件见下） | `false` | — | 内容安全检查参数；省略时仅在表中存在 default 才有已声明默认值。 |
| `prompt` | 字符串（string） | 必填 | 未声明 | 最多字符 800 | 描述要生成的画面，或参考图需要如何修改。 |
| `resolution` | 字符串（string） | 否（条件见下） | `1K` | 仅 `1K`、`2K` | 原样传入表中大小写，不将 1K、1k、1MP 混为同一枚举。 |
| `size` | 字符串（string） | 否（条件见下） | `1:1` | 仅 `1:1`、`4:3`、`3:4`、`16:9`、`9:16`、`3:2`、`2:3` | 比例、像素值或尺寸档位的具体含义按本型号规则；不要套用其他型号。 |

### 条件必填、互斥与结构规则

- 根级必填：`model`、`prompt`。


### 本组基础调用示例

```bash
curl --request POST \
  --url "https://api.onemini.top/v1/images/generations" \
  --header "Authorization: Bearer ${API_KEY}" \
  --header "Content-Type: application/json" \
  --data-raw '{
  "model": "qwen-image-2.0",
  "prompt": "一只橘猫坐在窗边，柔和自然光，画面简洁",
  "size": "1:1",
  "resolution": "1K",
  "n": 1
}'
```

调用本组其他型号时，只需把示例 `model` 换成上面同组的精确 ID；不要改成文档标题或自行删除后缀。
