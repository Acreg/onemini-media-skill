# Wan 2.7 图片系列

> **Onemini 图片 API 参数参考。** API 地址：`https://api.onemini.top`。更新日期：2026-11-15。

## 调用前准备

先设置正式站 API Key（以下示例使用 Bash）：

```bash
export API_KEY="替换成正式站 API Key"
```

表格中“—”表示未公布枚举或上下限；“未声明”表示没有明确公布默认值。可选参数仍须满足对应模式的条件。

## Pro 与普通版、单图与连续组图

- `wan2.7-image`：分辨率仅 `1K/2K`。
- `wan2.7-image-pro`：纯文生图可用 `1K/2K/4K`；**一旦带参考图或 `enable_sequential:true`，也只能用 `1K/2K`**。
- `enable_sequential` 为 false 或省略：`n≤4`；为 true：`n≤12`。不能只看参数基础表的 maximum=12。
- 可以只有 `image_urls` 而不带 `prompt`，但提供该字段的结构必须符合本型号规则；业务调用建议使用非空参考图数组。
- `color_palette[].ratio` 是字符串，不是数字；`bbox_list` 为三层数组，不能简化为任意二维坐标。

## 精确模型 ID

| model（原样填写） | 参数小节 | API 入口 |
| --- | --- | --- |
| `wan2.7-image` | 本文第 1 组参数 | `POST /v1/images/generations` |
| `wan2.7-image-pro` | 本文第 2 组参数 | `POST /v1/images/generations` |

## 响应与结果获取

提交接口为 `POST /v1/images/generations`。请求受理后返回 **HTTP 202**，任务号位于 `data.task_id`（也有 `data.id`）。任务号不是图片下载地址。

使用同一 API Key 调用 `GET /v1/media/tasks/{task_id}`；`data.status` 为 `succeeded` 后，普通图片的文件链接位于 `data.result.images[].url[]`。详细状态、轮询与停止流程见 [媒体任务查询、结果下载与请求停止](https://docs-api.onemini.top/9683548m0)。媒体任务号不使用 `/v1/images/tasks/{task_id}` 查询。

## 1. `wan2.7-image`

本组 ID 共享下列字段结构与约束；`model` 应填写所选的完整 ID，不是任选版本后缀。

### 型号参数表

| 参数 | 类型 | 是否必填 | 默认值 | 枚举、范围与结构约束 | 中文说明 |
| --- | --- | --- | --- | --- | --- |
| `bbox_list` | 数组<数组<数组<数值（number）>>> | 否（条件见下） | 未声明 | — | 多层数组表示的区域定位框；数组层级与元素数量见表，不推定未声明的坐标单位。 |
| `bbox_list[]` | 数组<数组<数值（number）>> | 每个数组元素 | 未声明 | 最多元素 2 | 数组层级约束。 |
| `bbox_list[][]` | 数组<数值（number）> | 每个数组元素 | 未声明 | 最少元素 4；最多元素 4 | 数组层级约束。 |
| `color_palette` | 数组<对象（object）> | 否（条件见下） | 未声明 | 最少元素 3；最多元素 10 | 调色板对象数组；每项必须同时提供 hex 和 ratio。 |
| `color_palette[].hex` | 字符串（string） | 父对象出现时必填 | 未声明 | — | 十六进制颜色；具体可用值见约束列。 |
| `color_palette[].ratio` | 字符串（string） | 父对象出现时必填 | 未声明 | — | 字符串类型的颜色占比；不要按其他接口改为数值。 |
| `enable_sequential` | 布尔（boolean） | 否（条件见下） | `false` | — | 开启连续组图后，允许的 n 和分辨率可能改变。 |
| `image_urls` | 数组<字符串（string）> | 否（条件见下） | 未声明 | 最多元素 9 | 文生图时省略；图生图或编辑时传入可读取的图片地址。 |
| `model` | 字符串（string） | 必填 | 未声明 | 固定 `wan2.7-image` | 请求时原样填写本节列出的 ID；不同后缀是不同模型。 |
| `n` | 整数（integer） | 否（条件见下） | `1` | 最小 1；最大 12 | 一次请求的生成数量；分层模型中不等于返回图层数。 |
| `negative_prompt` | 字符串（string） | 否（条件见下） | 未声明 | — | 负面提示词；具体可用值见约束列。 |
| `nsfw_check` | 布尔（boolean） | 否（条件见下） | `false` | — | 内容安全检查参数；省略时仅在表中存在 default 才有已声明默认值。 |
| `prompt` | 字符串（string） | 否（条件见下） | 未声明 | 最多字符 5000 | 描述要生成的画面，或参考图需要如何修改。 |
| `resolution` | 字符串（string） | 否（条件见下） | 未声明 | 仅 `1K`、`2K` | 原样传入表中大小写，不将 1K、1k、1MP 混为同一枚举。 |
| `seed` | 整数（integer） | 否（条件见下） | 未声明 | 最小 0；最大 2147483647 | 随机种子；不额外承诺跨版本或跨渠道的逐像素复现。 |
| `size` | 字符串（string） | 否（条件见下） | 未声明 | 满足至少一种：方案1 仅 `1K`、`2K`；方案2 仅 `1:1`、`4:3`、`3:4`、`16:9`、`9:16`、`3:2`、`2:3`；方案3 正则 `^[1-9][0-9]*[x*][1-9][0-9]*$`；文档尺寸范围（不是已强制执行的逐边界限）：≤2048x2048、≥768x768 | 比例、像素值或尺寸档位的具体含义按本型号规则；不要套用其他型号。 支持 1K／2K、所列比例或精确像素，文档像素范围为 768×768～2048×2048；不支持 4K，比例默认采用 2K 档位。 |
| `thinking_mode` | 布尔（boolean） | 否（条件见下） | `true` | — | 思考模式；具体可用值见约束列。 |
| `watermark` | 布尔（boolean） | 否（条件见下） | `false` | — | 水印；具体可用值见约束列。 |

### 条件必填、互斥与结构规则

- 根级必填：`model`。
- 至少满足一项：[必须提供 `prompt`] 或 [必须提供 `image_urls`]。
- 当 必须提供 `enable_sequential`；`enable_sequential` 固定 `true` 时，`n` 最大 12；否则 `n` 最大 4。
- 当 至少满足一项：[必须提供 `image_urls`；`image_urls` 最少元素 1] 或 [必须提供 `enable_sequential`；`enable_sequential` 固定 `true`] 时，`resolution` 仅 `1K`、`2K`；`size` 满足至少一种：方案1 仅 `1K`、`2K`；方案2 仅 `1:1`、`4:3`、`3:4`、`16:9`、`9:16`、`3:2`、`2:3`；方案3 正则 `^[1-9][0-9]*[x*][1-9][0-9]*$`；文档尺寸范围（不是已强制执行的逐边界限）：≤2048x2048、≥768x768。

### 本组基础调用示例

```bash
curl --request POST \
  --url "https://api.onemini.top/v1/images/generations" \
  --header "Authorization: Bearer ${API_KEY}" \
  --header "Content-Type: application/json" \
  --data-raw '{
  "model": "wan2.7-image",
  "prompt": "一只橘猫坐在窗边，柔和自然光，画面简洁",
  "n": 1
}'
```
