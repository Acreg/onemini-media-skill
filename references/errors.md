# 中文排障指南

先区分三件事：请求是否已受理、任务是否已生成成功、文件是否已下载。它们不是同一个状态。

输出按“出了什么问题 → 已知或可能原因 → 该怎么处理”组织。附已脱敏的 HTTP 状态、业务 code/message、请求标识或任务号；不要输出 Key、Authorization 或完整认证配置。不凭 HTTP 状态单独断言根因。

| 场景 | 常见原因与下一步 |
|---|---|
| 未配置密钥 | 执行初始化，让用户在本地安全标注 .env 中填写创作密钥；不要让用户把 Key 发到聊天里 |
| 401 / 403 | Key 无效、环境不匹配、创作密钥分组或模型权限不足；核对目录与实际业务错误，不打印 Key |
| 400 / 422 | 精确 model ID、参数类型/枚举、条件必填、互斥、素材或来源任务错误，也可能是缺少可用报价；读取实际 message/details，对照该型号文档修正 |
| 404 | 路径/线路/环境不对、任务不属于当前 Key、混用了原生与统一任务协议，或错误使用内容下载路由；不要直接断言“模型已下线” |
| 409 | 幂等标识对应不同请求，或原请求已在处理；先查询原单。参数变化需要新请求，但不能用新标识盲目重放未知提交 |
| 429 | 并发或速率受限；遵守服务端等待时间。不把余额不足和频率限制混为一谈 |
| 502 / 503 | 目录、线路、存储或模型服务可能暂不可用；已取得任务号先查原任务，未确认提交前不自动跨线路另开一单 |
| 额度/余额/Key限额业务错误 | 依真实业务 code/message 说明当前 Key 的额度或限额；HTTP 状态与业务码一起判断，不写死价格或“某状态必然没钱” |
| 素材无法读取 | URL 要可由模型访问；检查格式、大小、数量、有效期与目标型号素材字段。本地图片/视频按文档上传；没有统一音频上传路由 |
| 来源任务不可用 | 核对本人/同Key、兼容型号、任务状态和来源字段。下载 URL、上游ID、本站task_id不可互换 |
| 内容审核/模型拒绝 | 按实际错误说明；未披露原因就说未披露，不杜撰触发词、不连续重试 |
| HTTP成功但任务failed | 生成失败，展示任务中的 error；不能用空数组或下载占位文件冒充作品 |
| 超时/连接中断/submit_unknown | 不能确认是否已外发。保存原身份，使用本站任务号、X-Media-Task-ID或client_ref核对，不自动再生成 |
| 本地等待时间用完 | 服务端可能仍在生成；用已保存记录“继续”，不是“重新生成”，也不能说任务已取消 |
| 签名链接过期/下载失败 | 生成成功和下载成功分开报告；查询原任务取得仍有效的结果，原结果过期则如实说明，不悄悄重生成 |
| 文档站不可达 | 无法确认线上是否更新；继续用内置资料。生成API与文档站是不同入口 |
| 更新被拒绝/未确认 | 保持原文档，正常生成不受人为限制；下次需要时再检查 |

## 不要混用的协议

- 同步图片：直接处理 `data[].url` 或 `data[].b64_json`，不凭空构造任务ID。
- 统一媒体任务：`GET /v1/media/tasks/{task_id}`；HTTP 202 只代表受理/保存，不代表完成。
- 音乐：下载 Suno/Flowmusic 实际 `result` 音频URL；`/v1/media/tasks/{id}/content` 不是它们的通用音乐下载接口。
- 上传：统一入口只支持图片、视频；`/v1/media/uploads/audios` 不存在于这份契约。
- 取消：本地停止等待不等于取消。仅 `cancelled_before_dispatch` 且 `confirmed_not_dispatched=true` 能说明已确认未外发。
