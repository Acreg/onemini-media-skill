# Suno 音乐生成与角色风格

**接口地址：** `https://api.onemini.top/v1/music/generations`，方法 `POST`，请求体为 JSON。

**本篇精确型号：** `suno`。

鉴权、任务状态、报价及停止请求统一见[任务公共指南](https://docs-api.onemini.top/9683548m0)。本文只展开型号专属参数。表中“默认值”是参数说明中的默认选项；未指定的字段不额外推断默认值、枚举或上限。所有条件规则需要同时满足；传入 false 仍算“提供了该字段”。

## 调用前设置

将下面的占位内容替换为你自己的 API Key；后续命令统一使用 `API_KEY`。命令按 Bash 写法展示。

```bash
export API_KEY='替换为你的 API Key'
```

## 型号差异与操作选择

- model 固定 suno；version 仅为 v6／v6-wild／v6-mini。version 与 custom_model_id 必须且只能提供一个，不可同时传，也不可同时省略。
- 默认 custom=false、instrumental=false。非自定义 prompt 必填且最长 3000 字符；custom=true 且非纯音乐时必填且最长 5000 字符。只有 custom=true 且 instrumental=true 可省略。接口按 Unicode 字符数、去除空白判非空；自定义纯音乐若传 prompt 仍受 5000 字符接口上限约束。
- max_mode=true 必须显式 custom=true，按 2 个音乐计费单位处理，不是输出轨数。duration 只在 custom=true 使用，10–360 秒。
- persona_id 使用已有角色风格，与 custom_model_id 互斥；不是创建／查询／删除角色接口。custom_model_id 是已有自定义模型标识，不是本站视频草稿 task_id。
- 当前公开路由与参数规则没有 extend（续写）、cover（翻唱）、upload（上传音频生成／转换）、创建 persona、stems（分轨）操作；这些操作不属于本文音乐生成接口。audio_weight 存在也不等于音频上传已接通。
- 音乐从 task.result 实际 URL 下载，不使用媒体任务 content 路由。

## 参数与提交示例

参数表包含嵌套字段；数组元素以 `[]` 标记。“父项出现时必填”不强制可选父字段存在。同系列型号也可能采用不同字段或组合限制，请按准确型号调用。示例素材 `example.com` 为占位符，必须替换为可公开读取的真实素材 URL。

### 必填、互斥与条件规则

- 必填：`model`。
- 至少提供 `version` 或 `custom_model_id`。
- 不得同时提供 `version`、`custom_model_id`。
- 不得同时提供 `persona_id`、`custom_model_id`。
- 当`custom` 为 `true`时，当`instrumental` 未设置为 `true`时，`prompt`（如提供）至少 1 字符，最多 5000 字符；否则，`prompt`（如提供）至少 1 字符，最多 3000 字符。
- 当`max_mode` 为 `true`时，`custom` 为 `true`。
- 当提供 `duration`时，`custom` 为 `true`。

输入模式：文字生成。各模式均须满足本型号的必填和组合限制。

### 来源任务

本型号不提供本站草稿／续写来源任务字段；素材 URL 与任务 ID 不能混用。

### 提交示例

```bash
curl --fail-with-body -sS "https://api.onemini.top/v1/music/generations" \
  -H "Authorization: Bearer ${API_KEY}" \
  -H "Content-Type: application/json" \
  --data-raw '{
  "model": "suno",
  "version": "v6",
  "custom": false,
  "instrumental": false,
  "prompt": "一首轻快温暖的中文流行歌曲，主题是春天的重逢",
  "audio_format": "mp3"
}' \
  -o submit.json
```

## 专属模式请求体补充

以下 JSON 提交到本篇开头的同一个接口，可替换 curl 的 `--data-raw` 请求体。来源占位符须先按来源查询步骤取得。

### 自定义歌词、人声与已有 persona（不同时传 custom_model_id）

```json
{
  "model": "suno",
  "version": "v6",
  "custom": true,
  "instrumental": false,
  "prompt": "[Verse]\n雨后的街角，灯光温柔\n[Chorus]\n愿每次重逢，都有新的问候",
  "title": "新的问候",
  "style": "温暖的中文流行，钢琴与原声吉他",
  "persona_id": "REPLACE_WITH_EXISTING_PERSONA_ID",
  "vocal_gender": "Female",
  "style_weight": 0.7,
  "duration": 60,
  "audio_format": "mp3"
}
```

### 自定义纯音乐可省略 prompt；增强模式要求 custom=true

```json
{
  "model": "suno",
  "version": "v6-mini",
  "custom": true,
  "instrumental": true,
  "style": "轻柔钢琴与弦乐",
  "duration": 30,
  "max_mode": true,
  "audio_format": "mp3"
}
```

## 查询与下载

提交成功返回 HTTP 202，任务对象位于 `data`。以下命令从 `data.task_id` 读取本次任务 ID。

```bash
TASK_ID=$(jq -er '.data.task_id' submit.json)
curl --fail-with-body -sS "https://api.onemini.top/v1/media/tasks/${TASK_ID}" \
  -H "Authorization: Bearer ${API_KEY}" \
  -o task.json
jq '.data | {task_id, model, status, result, error}' task.json
```

未到 `succeeded` 时按公共指南继续查询同一任务；不要把“已接收”当成媒体已经生成。成功后才执行下载：

```bash
MEDIA_URL=$(jq -er '.data.result.audios[0].url[0]' task.json)
curl --fail --location "$MEDIA_URL" --output output.mp3
```

示例取第一项；有多个结果时遍历真实结果列表。素材／结果 URL 不需要转发本站 API Key。文件后缀应按实际输出格式调整。

音乐结果会标准化到 `data.result.audios[]`，每项 `url` 是 URL 数组；原有 `data.result.music[]` 也可能保留。**不要用 `/v1/media/tasks/{id}/content` 下载 Suno／Flowmusic**，该路由不是音乐下载实现。

停止未外发请求与上游任务撤销不是同一功能；取消和幂等说明统一见[任务公共指南](https://docs-api.onemini.top/9683548m0)。本组不承诺可撤销已外发任务。
