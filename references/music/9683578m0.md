# Flowmusic 音乐生成

**接口地址：** `https://api.onemini.top/v1/music/generations`，方法 `POST`，请求体为 JSON。

**本篇精确型号：** `flowmusic`。

鉴权、任务状态、报价及停止请求统一见[任务公共指南](https://docs-api.onemini.top/9683548m0)。本文只展开型号专属参数。表中“默认值”是参数说明中的默认选项；未指定的字段不额外推断默认值、枚举或上限。所有条件规则需要同时满足；传入 false 仍算“提供了该字段”。

## 调用前设置

将下面的占位内容替换为你自己的 API Key；后续命令统一使用 `API_KEY`。命令按 Bash 写法展示。

```bash
export API_KEY='替换为你的 API Key'
```

## 型号差异与操作选择

- model 固定 flowmusic；version 若传只能 lyria-3.5。
- sound_prompt 与 lyrics 至少一个是非空字符串，接口将纯空白也视为空。
- bpm 和 seed 都是字符串，例如 bpm="120"、seed="42"，不能传 JSON 数字。bpm 描述要求数字字符串且数值至少 1；本站 schema 没有正则、上限或小数格式，不自行补造整数范围。
- length 是 1–240 的整数秒，没有声明默认长度、节拍或随机种子。
- 无本站来源任务续写／翻唱／分轨参数规则；结果从 task.result 实际音乐 URL 下载，不使用媒体任务 content 接口。

## 参数与提交示例

参数表包含嵌套字段；数组元素以 `[]` 标记。“父项出现时必填”不强制可选父字段存在。同系列型号也可能采用不同字段或组合限制，请按准确型号调用。示例素材 `example.com` 为占位符，必须替换为可公开读取的真实素材 URL。

## `flowmusic`

| 参数 | 中文含义 | 类型 | 必填 | 默认值 | 枚举／范围／说明 |
|---|---|---|---|---|---|
| `bpm` | 节奏（每分钟拍数） | 字符串 | 否／按组合规则 | 未声明 | 未声明额外枚举或范围；节奏使用数字字符串，数值至少为1；具体数值格式由上游校验。 |
| `length` | 音频时长（秒） | 整数 | 否／按组合规则 | 未声明 | ≥ `1`；≤ `240` |
| `lyrics` | 歌词 | 字符串 | 否／按组合规则 | 未声明 | 未声明额外枚举或范围 |
| `model` | 模型 ID | 字符串 | 是 | 未声明 | 固定为 `"flowmusic"` |
| `seed` | 随机种子 | 字符串 | 否／按组合规则 | 未声明 | 未声明额外枚举或范围 |
| `sound_prompt` | 声音描述 | 字符串 | 否／按组合规则 | 未声明 | 未声明额外枚举或范围 |
| `title` | 标题 | 字符串 | 否／按组合规则 | 未声明 | 未声明额外枚举或范围 |
| `version` | 模型版本 | 字符串 | 否／按组合规则 | 未声明 | 固定为 `"lyria-3.5"` |

### 必填、互斥与条件规则

- 必填：`model`。
- 满足以下至少一种：（`sound_prompt`（如提供）至少 1 字符）；或 （`lyrics`（如提供）至少 1 字符）。

### 来源任务

本型号不提供本站草稿／续写来源任务字段；素材 URL 与任务 ID 不能混用。

### 提交示例

```bash
curl --fail-with-body -sS "https://api.onemini.top/v1/music/generations" \
  -H "Authorization: Bearer ${API_KEY}" \
  -H "Content-Type: application/json" \
  --data-raw '{
  "model": "flowmusic",
  "sound_prompt": "轻柔钢琴与弦乐，适合作为阅读背景音乐",
  "bpm": "90",
  "length": 30,
  "seed": "42",
  "version": "lyria-3.5"
}' \
  -o submit.json
```

## 专属模式请求体补充

以下 JSON 提交到本篇开头的同一个接口，可替换 curl 的 `--data-raw` 请求体。来源占位符须先按来源查询步骤取得。

### 仅歌词入口（无需同时提供 sound_prompt）

```json
{
  "model": "flowmusic",
  "lyrics": "春风穿过小巷，带来温柔的光",
  "bpm": "100",
  "length": 30,
  "seed": "42"
}
```

## 查询与下载

提交成功返回 HTTP 202，任务对象位于 `data`。以下命令从 `data.task_id` 读取本次任务 ID。

```bash
TASK_ID=$(jq -er '.data.task_id' submit.json)
curl --fail-with-body -sS "https://api.onemini.top/v1/media/tasks/${TASK_ID}" \
  -H "Authorization: Bearer ${API_KEY}" \
  -o task.json
jq '.data | {task_id, model, status, result, error}' task.json
```

未到 `succeeded` 时按公共指南继续查询同一任务；不要把“已接收”当成媒体已经生成。成功后才执行下载：

```bash
MEDIA_URL=$(jq -er '.data.result.audios[0].url[0]' task.json)
curl --fail --location "$MEDIA_URL" --output output.mp3
```

示例取第一项；有多个结果时遍历真实结果列表。素材／结果 URL 不需要转发本站 API Key。文件后缀应按实际输出格式调整。

音乐结果会标准化到 `data.result.audios[]`，每项 `url` 是 URL 数组；原有 `data.result.music[]` 也可能保留。**不要用 `/v1/media/tasks/{id}/content` 下载 Suno／Flowmusic**，该路由不是音乐下载实现。

停止未外发请求与上游任务撤销不是同一功能；取消和幂等说明统一见[任务公共指南](https://docs-api.onemini.top/9683548m0)。本组不承诺可撤销已外发任务。
