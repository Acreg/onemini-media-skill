# Gemini Omni 视频与 Omni-Flash-Ext

**接口地址：** `https://api.onemini.top/v1/videos/generations`，方法 `POST`，请求体为 JSON。

**本篇精确型号：** `gemini-omni-1.1-flash`、`gemini-omni-1.2-flash`、`gemini-omni-1.2-flash-ext`、`gemini-omni-flash-preview`、`Omni-Flash-Ext`。

鉴权、任务状态、报价及停止请求统一见[任务公共指南](https://docs-api.onemini.top/9683548m0)。本文只展开型号专属参数。表中“默认值”是参数说明中的默认选项；未指定的字段不额外推断默认值、枚举或上限。所有条件规则需要同时满足；传入 false 仍算“提供了该字段”。

## 调用前设置

将下面的占位内容替换为你自己的 API Key；后续命令统一使用 `API_KEY`。命令按 Bash 写法展示。

```bash
export API_KEY='替换为你的 API Key'
```

## 型号差异与操作选择

- 四个 gemini-omni 型号与大小写固定的 Omni-Flash-Ext 是五个独立 ID，不能按别名替换。
- 1.2／1.2-ext 为 3–15 秒、默认 10 秒；有尾帧或任务类型 extend 时上限 10 秒。尾帧必须有首帧。
- 1.2-ext 的 generation_type 与 omni_reference_task_type 互斥，video_urls 与 video_url 互斥；有尾帧时禁止 negative_prompt／system_prompt。
- 1.1 的 metadata 嵌套参数照表，不把通用 duration 误认成 1.2 的范围。preview 固定 720p，extend_from_task_id 与 video_urls 互斥。
- extend_from_task_id 是本站来源引用而非 URL。1.1 允许四个 Gemini Omni 型号来源；1.2-ext 仅接受同型号来源；1.2 和 preview 未给来源型号白名单，不能据此宣称任意厂商视频都兼容。
- Omni-Flash-Ext 时长为 4／6／8／10 秒、默认 8，清晰度为 360p／720p／1080p／4k；未声明可解析的 extend_from_task_id，名称 Ext 不等于本地任务续写。

## 参数与提交示例

参数表包含嵌套字段；数组元素以 `[]` 标记。“父项出现时必填”不强制可选父字段存在。同系列型号也可能采用不同字段或组合限制，请按准确型号调用。示例素材 `example.com` 为占位符，必须替换为可公开读取的真实素材 URL。

### 必填、互斥与条件规则

- 必填：`model`。
- 至少提供 `prompt` 或 `image_urls` 或 `image_with_roles` 或 `first_frame_image` 或 `last_frame_image` 或 `video_urls`。
- 当提供 `last_frame_image`时，必须提供 `first_frame_image`。

输入模式：文字生成、图片参考生成、视频参考生成。各模式均须满足本型号的必填和组合限制。

### 来源任务

来源值必须使用本站任务记录提供的 `source_reference.value`；不是上游私有 task ID、视频 URL 或工作站素材 ID。要求属于本人同一 API Key、同一线路且已成功完成，服务端会选择原来源线路并转换后再提交。一次请求只选择一种来源任务字段。

#### `extend_from_task_id`

- 来源型号：`gemini-omni-1.2-flash-ext`、`gemini-omni-1.2-flash`、`gemini-omni-1.1-flash`、`gemini-omni-flash-preview`。

查询候选来源（`source_model` 填本次目标型号）：

```bash
curl --fail-with-body -sS -G "https://api.onemini.top/v1/media/tasks" \
  -H "Authorization: Bearer ${API_KEY}" \
  --data-urlencode "source_model=gemini-omni-1.1-flash" \
  --data-urlencode "source_field=extend_from_task_id" \
  --data-urlencode "page=1" --data-urlencode "limit=50" \
  -o source-page.json
jq '.data[] | {task_id: .task_id, value: .source_reference.value}' source-page.json
```

必须跟进 `has_more`；本页 `data` 为空不代表后面没有符合条件的任务。选中正确条目的 `source_reference.value`，替换提交示例中的 `REPLACE_WITH_SOURCE_REFERENCE_VALUE`。分页与任务选择细节见[任务公共指南](https://docs-api.onemini.top/9683548m0)。

### 提交示例

```bash
curl --fail-with-body -sS "https://api.onemini.top/v1/videos/generations" \
  -H "Authorization: Bearer ${API_KEY}" \
  -H "Content-Type: application/json" \
  --data-raw '{
  "model": "gemini-omni-1.1-flash",
  "prompt": "镜头缓慢推进，清晨阳光照亮森林，画面自然平稳",
  "resolution": "720p"
}' \
  -o submit.json
```

### 必填、互斥与条件规则

- 必填：`model`、`prompt`。
- 不得同时提供 `extend_from_task_id`、`video_urls`。

输入模式：文字生成、图片参考生成、视频参考生成。各模式均须满足本型号的必填和组合限制。

### 来源任务

来源值必须使用本站任务记录提供的 `source_reference.value`；不是上游私有 task ID、视频 URL 或工作站素材 ID。要求属于本人同一 API Key、同一线路且已成功完成，服务端会选择原来源线路并转换后再提交。一次请求只选择一种来源任务字段。

#### `extend_from_task_id`

- 来源型号兼容范围未列出白名单，不应推断任意其他型号都支持。

查询候选来源（`source_model` 填本次目标型号）：

```bash
curl --fail-with-body -sS -G "https://api.onemini.top/v1/media/tasks" \
  -H "Authorization: Bearer ${API_KEY}" \
  --data-urlencode "source_model=gemini-omni-flash-preview" \
  --data-urlencode "source_field=extend_from_task_id" \
  --data-urlencode "page=1" --data-urlencode "limit=50" \
  -o source-page.json
jq '.data[] | {task_id: .task_id, value: .source_reference.value}' source-page.json
```

必须跟进 `has_more`；本页 `data` 为空不代表后面没有符合条件的任务。选中正确条目的 `source_reference.value`，替换提交示例中的 `REPLACE_WITH_SOURCE_REFERENCE_VALUE`。分页与任务选择细节见[任务公共指南](https://docs-api.onemini.top/9683548m0)。

## 查询与下载

提交成功返回 HTTP 202，任务对象位于 `data`。以下命令从 `data.task_id` 读取本次任务 ID。

```bash
TASK_ID=$(jq -er '.data.task_id' submit.json)
curl --fail-with-body -sS "https://api.onemini.top/v1/media/tasks/${TASK_ID}" \
  -H "Authorization: Bearer ${API_KEY}" \
  -o task.json
jq '.data | {task_id, model, status, result, error}' task.json
```

未到 `succeeded` 时按公共指南继续查询同一任务；不要把“已接收”当成媒体已经生成。成功后才执行下载：

```bash
MEDIA_URL=$(jq -er '.data.result.videos[0].url[0]' task.json)
curl --fail --location "$MEDIA_URL" --output output.mp4
```

示例取第一项；有多个结果时遍历真实结果列表。素材／结果 URL 不需要转发本站 API Key。文件后缀应按实际输出格式调整。

视频结果 URL 从 `data.result.videos[].url[]` 读取；本组媒体任务没有通用视频 content 下载实现。不能把原生 `/v1/videos/{id}/content` 当成本组任务的下载路由。

停止未外发请求与上游任务撤销不是同一功能；取消和幂等说明统一见[任务公共指南](https://docs-api.onemini.top/9683548m0)。本组不承诺可撤销已外发任务。
