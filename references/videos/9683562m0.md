# Seedance 2.0 多模态与 face 变体

**接口地址：** `https://api.onemini.top/v1/videos/generations`，方法 `POST`，请求体为 JSON。

**本篇精确型号：** `seedance-2.0`、`seedance-2.0-fast`、`seedance-2.0-mini`、`seedance-2.0-face`、`seedance-2.0-fast-face`。

鉴权、任务状态、报价及停止请求统一见[任务公共指南](https://docs-api.onemini.top/9683548m0)。本文只展开型号专属参数。表中“默认值”是参数说明中的默认选项；未指定的字段不额外推断默认值、枚举或上限。所有条件规则需要同时满足；传入 false 仍算“提供了该字段”。

## 调用前设置

将下面的占位内容替换为你自己的 API Key；后续命令统一使用 `API_KEY`。命令按 Bash 写法展示。

```bash
export API_KEY='替换为你的 API Key'
```

## 型号差异与操作选择

- 标准 2.0、fast、mini 与 face／fast-face 是五个独立型号。标准 2.0 可用 1080p／4k；fast、mini 的已声明清晰度是 480p／720p。face 两型号未列出固定时长和清晰度选项，不能沿用非 face 的时长、清晰度或多模态上限。
- 非 face 三型号：image_urls 与 image_with_roles 互斥；角色图片含 first_frame／last_frame 时不能同时带 video_urls／audio_urls；音频参考不能作为唯一输入。
- 非 face 的 image_with_roles 每项 url 和 role 都必填，role 为 first_frame／last_frame／reference_image；不能写成纯 URL 字符串。
- generate_audio 控制生成声音，audio_urls 是参考声音，二者不同。
- 本组接口使用 prompt／image_with_roles／video_urls／audio_urls，不要把另一套原生任务协议的 content 数组混入。

## 参数与提交示例

参数表包含嵌套字段；数组元素以 `[]` 标记。“父项出现时必填”不强制可选父字段存在。同系列型号也可能采用不同字段或组合限制，请按准确型号调用。示例素材 `example.com` 为占位符，必须替换为可公开读取的真实素材 URL。

| 参数 | 中文含义 | 类型 | 必填 | 默认值 | 枚举／范围／说明 |
|---|---|---|---|---|---|
| `aspect_ratio` | 画面比例 | 字符串 | 否／按组合规则 | 未声明 | 未声明额外枚举或范围 |
| `audio_urls` | 参考音频 URL 列表 | 数组 | 否／按组合规则 | 未声明 | 至少 1 项；至多 3 项；元素：字符串 |
| `duration` | 输出时长（秒） | 整数 | 否／按组合规则 | `5` | ≥ `4`；≤ `15` |
| `first_frame_image` | 首帧图片 URL | 字符串 | 否／按组合规则 | 未声明 | 未声明额外枚举或范围 |
| `generate_audio` | 生成声音 | 布尔值 | 否／按组合规则 | `true` | 未声明额外枚举或范围 |

| `image_with_roles` | 带角色的图片列表 | 数组 | 否／按组合规则 | 未声明 | 至少 1 项 |
| `image_with_roles[].role` | 素材／消息角色 | 字符串 | 父项出现时必填 | 未声明 | 可选 `"first_frame"`、`"last_frame"`、`"reference_image"` |
| `image_with_roles[].url` | URL 兼容字段 | 字符串 | 父项出现时必填 | 未声明 | 未声明额外枚举或范围 |
| `last_frame_image` | 尾帧图片 URL | 字符串 | 否／按组合规则 | 未声明 | 未声明额外枚举或范围 |
| `messages` | 兼容提示词消息列表 | 数组 | 否／按组合规则 | 未声明 | 至少 1 项 |
| `messages[].content` | 消息内容 | 字符串 | 父项出现时必填 | 未声明 | 至少 1 个字符 |
| `messages[].role` | 素材／消息角色 | 字符串 | 否／按组合规则 | 未声明 | 未声明额外枚举或范围 |
| `model` | 模型 ID | 字符串 | 是 | 未声明 | 固定为 `"seedance-2.0"` |
| `nsfw_check` | 内容审核选项 | 布尔值 | 否／按组合规则 | `false` | 未声明额外枚举或范围 |
| `prompt` | 生成描述／提示词 | 字符串 | 否／按组合规则 | 未声明 | 至少 1 个字符；至多 4000 个字符 |
| `resolution` | 清晰度 | 字符串 | 否／按组合规则 | `"720p"` | 可选 `"480p"`、`"720p"`、`"1080p"`、`"4k"` |
| `return_last_frame` | 返回尾帧 | 布尔值 | 否／按组合规则 | `false` | 未声明额外枚举或范围 |
| `seed` | 随机种子 | 整数 | 否／按组合规则 | 未声明 | 未声明额外枚举或范围 |
| `size` | 画面尺寸／比例 | 字符串 | 否／按组合规则 | `"16:9"` | 可选 `"16:9"`、`"9:16"`、`"1:1"`、`"4:3"`、`"3:4"`、`"21:9"`、`"adaptive"` |
| `tools` | 增强工具 | 数组 | 否／按组合规则 | 未声明 | 未声明额外枚举或范围 |
| `tools[].type` | 工具类型 | 字符串 | 父项出现时必填 | 未声明 | 可选 `"web_search"` |
| `video_urls` | 输入／参考视频 URL 列表 | 数组 | 否／按组合规则 | 未声明 | 至少 1 项；至多 3 项；元素：字符串 |

### 必填、互斥与条件规则

- 必填：`model`。
- 至少提供 `prompt` 或 `messages` 或 `image_urls` 或 `image_with_roles` 或 `video_urls`。
- 不得同时提供 `image_urls`、`image_with_roles`。
- 当`image_with_roles` 至少一个元素满足：`role` 为 `"first_frame"`／`"last_frame"`时，不得提供以下字段：`video_urls`、`audio_urls`。
- 当提供 `audio_urls`时，至少提供 `image_urls` 或 `image_with_roles` 或 `video_urls`。

输入模式：文字生成、图片参考生成、视频参考生成、音频参考生成。各模式均须满足本型号的必填和组合限制。

### 来源任务

本型号不提供本站草稿／续写来源任务字段；素材 URL 与任务 ID 不能混用。

### 提交示例

```bash
curl --fail-with-body -sS "https://api.onemini.top/v1/videos/generations" \
  -H "Authorization: Bearer ${API_KEY}" \
  -H "Content-Type: application/json" \
  --data-raw '{
  "model": "seedance-2.0",
  "prompt": "镜头缓慢推进，清晨阳光照亮森林，画面自然平稳",
  "duration": 5,
  "resolution": "720p"
}' \
  -o submit.json
```

## 查询与下载

提交成功返回 HTTP 202，任务对象位于 `data`。以下命令从 `data.task_id` 读取本次任务 ID。

```bash
TASK_ID=$(jq -er '.data.task_id' submit.json)
curl --fail-with-body -sS "https://api.onemini.top/v1/media/tasks/${TASK_ID}" \
  -H "Authorization: Bearer ${API_KEY}" \
  -o task.json
jq '.data | {task_id, model, status, result, error}' task.json
```

未到 `succeeded` 时按公共指南继续查询同一任务；不要把“已接收”当成媒体已经生成。成功后才执行下载：

```bash
MEDIA_URL=$(jq -er '.data.result.videos[0].url[0]' task.json)
curl --fail --location "$MEDIA_URL" --output output.mp4
```

示例取第一项；有多个结果时遍历真实结果列表。素材／结果 URL 不需要转发本站 API Key。文件后缀应按实际输出格式调整。

视频结果 URL 从 `data.result.videos[].url[]` 读取；本组媒体任务没有通用视频 content 下载实现。不能把原生 `/v1/videos/{id}/content` 当成本组任务的下载路由。

停止未外发请求与上游任务撤销不是同一功能；取消和幂等说明统一见[任务公共指南](https://docs-api.onemini.top/9683548m0)。本组不承诺可撤销已外发任务。
