# Seedance 2.5 多模态、草稿、编辑与续写

**接口地址：** `https://api.onemini.top/v1/videos/generations`，方法 `POST`，请求体为 JSON。

**本篇精确型号：** `seedance-2.5`。

鉴权、任务状态、报价及停止请求统一见[任务公共指南](https://docs-api.onemini.top/9683548m0)。本文只展开型号专属参数。表中“默认值”是参数说明中的默认选项；未指定的字段不额外推断默认值、枚举或上限。所有条件规则需要同时满足；传入 false 仍算“提供了该字段”。

## 调用前设置

将下面的占位内容替换为你自己的 API Key；后续命令统一使用 `API_KEY`。命令按 Bash 写法展示。

```bash
export API_KEY='替换为你的 API Key'
```

## 型号差异与操作选择

- 支持文字、图片、视频与音频参考。image_urls／image_with_roles 各最多 30 项，video_urls／audio_urls 各最多 10 项；逐字段上限不等于任意组合都能使用。
- duration 为 4–30 的整数，或 -1 自动时长。普通模式默认 720p；draft=true 要求 480p；draft_task_id 转正式要求 1080p。
- omni_reference_task_type=edit 必须有 video_urls；duration 若传只能为 -1，size／aspect_ratio 若传只能为 adaptive。extend 同样必须有视频，所传比例只能为 adaptive。续写用输入视频，不是把任务 ID 填进 video_urls。
- 只有首尾帧、没有视频／音频参考时，size／aspect_ratio 若传只能为 adaptive。
- 转正式只引用已完成同型号草稿，距创建时间须严格小于 259200 秒（72 小时）。提交 draft_task_id 时禁止重传提示、素材、时长、比例、种子、声音、任务类型等；draft=true 和 service_tier 也不允许，完整逐项限制见组合规则。
- 参考视频真实总时长由服务端检测，不得超过 30 秒。
- 实际按完成结果的视频 Token 用量结算；完成但用量未齐时应继续查询原任务，不要为补用量重新提交。

### 必填、互斥与条件规则

- 必填：`model`。
- 至少提供 `prompt` 或 `draft_task_id`。
- 当`draft` 为 `true`时，`resolution`（如提供）必须为 `"480p"`；不得提供以下字段：`draft_task_id`、`service_tier`。
- 当提供 `draft_task_id`时，`resolution`（如提供）必须为 `"1080p"`；`draft` 不得为 `true`；不得提供以下字段：`service_tier`；不得提供以下字段：`prompt`、`image_urls`、`image_with_roles`、`video_urls`、`audio_urls`、`duration`、`size`、`aspect_ratio`、`seed`、`generate_audio`、`audio`、`omni_reference_task_type`、`generation_type`、`camerafixed`、`web_search`、`tools`。
- 当不满足：满足以下至少一种：（`draft` 为 `true`）；或 （提供 `draft_task_id`）时，。
- 当`omni_reference_task_type` 为 `"edit"`时，必须提供 `video_urls`；`aspect_ratio`（如提供）必须为 `"adaptive"`；`duration`（如提供）必须为 `-1`；`size`（如提供）必须为 `"adaptive"`。
- 当`omni_reference_task_type` 为 `"extend"`时，必须提供 `video_urls`；`aspect_ratio`（如提供）必须为 `"adaptive"`；`size`（如提供）必须为 `"adaptive"`。
- 当`image_with_roles` 至少一个元素满足：`role` 为 `"first_frame"`／`"last_frame"`；未提供以下任一字段：`video_urls`、`audio_urls`时，`aspect_ratio`（如提供）必须为 `"adaptive"`；`size`（如提供）必须为 `"adaptive"`。

输入模式：文字生成、图片参考生成、视频参考生成、音频参考生成。各模式均须满足本型号的必填和组合限制。

### 来源任务

来源值必须使用本站任务记录提供的 `source_reference.value`；不是上游私有 task ID、视频 URL 或工作站素材 ID。要求属于本人同一 API Key、同一线路且已成功完成，服务端会选择原来源线路并转换后再提交。一次请求只选择一种来源任务字段。

#### `draft_task_id`

- 来源型号：`seedance-2.5`。
- 来源必须为成功草稿，不能引用普通成片或失败任务。
- 从来源创建时间计算，年龄严格小于 259200 秒。

查询候选来源（`source_model` 填本次目标型号）：

```bash
curl --fail-with-body -sS -G "https://api.onemini.top/v1/media/tasks" \
  -H "Authorization: Bearer ${API_KEY}" \
  --data-urlencode "source_model=seedance-2.5" \
  --data-urlencode "source_field=draft_task_id" \
  --data-urlencode "page=1" --data-urlencode "limit=50" \
  -o source-page.json
jq '.data[] | {task_id: .task_id, value: .source_reference.value}' source-page.json
```

必须跟进 `has_more`；本页 `data` 为空不代表后面没有符合条件的任务。选中正确条目的 `source_reference.value`，替换提交示例中的 `REPLACE_WITH_SOURCE_REFERENCE_VALUE`。分页与任务选择细节见[任务公共指南](https://docs-api.onemini.top/9683548m0)。

### 提交示例

```bash
curl --fail-with-body -sS "https://api.onemini.top/v1/videos/generations" \
  -H "Authorization: Bearer ${API_KEY}" \
  -H "Content-Type: application/json" \
  --data-raw '{
  "model": "seedance-2.5",
  "prompt": "镜头缓慢推进，清晨阳光照亮森林，画面自然平稳",
  "duration": 5
}' \
  -o submit.json
```

## 专属模式请求体补充

以下 JSON 提交到本篇开头的同一个接口，可替换 curl 的 `--data-raw` 请求体。来源占位符须先按来源查询步骤取得。


## 查询与下载

提交成功返回 HTTP 202，任务对象位于 `data`。以下命令从 `data.task_id` 读取本次任务 ID。

```bash
TASK_ID=$(jq -er '.data.task_id' submit.json)
curl --fail-with-body -sS "https://api.onemini.top/v1/media/tasks/${TASK_ID}" \
  -H "Authorization: Bearer ${API_KEY}" \
  -o task.json
jq '.data | {task_id, model, status, result, error}' task.json
```

未到 `succeeded` 时按公共指南继续查询同一任务；不要把“已接收”当成媒体已经生成。成功后才执行下载：

```bash
MEDIA_URL=$(jq -er '.data.result.videos[0].url[0]' task.json)
curl --fail --location "$MEDIA_URL" --output output.mp4
```

示例取第一项；有多个结果时遍历真实结果列表。素材／结果 URL 不需要转发本站 API Key。文件后缀应按实际输出格式调整。

视频结果 URL 从 `data.result.videos[].url[]` 读取；本组媒体任务没有通用视频 content 下载实现。不能把原生 `/v1/videos/{id}/content` 当成本组任务的下载路由。

停止未外发请求与上游任务撤销不是同一功能；取消和幂等说明统一见[任务公共指南](https://docs-api.onemini.top/9683548m0)。本组不承诺可撤销已外发任务。
