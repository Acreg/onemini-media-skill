# Wan 2.5、2.6、2.7 与 3.0 视频

**接口地址：** `https://api.onemini.top/v1/videos/generations`，方法 `POST`，请求体为 JSON。

**本篇精确型号：** `wan2.5-preview`、`wan2.6`、`wan2.6-i2v`、`wan2.6-i2v-flash`、`wan2.7`、`wan2.7-r2v`、`wan2.7-videoedit`、`wan3.0-video`、`wan3.0-video-prime`。

鉴权、任务状态、报价及停止请求统一见[任务公共指南](https://docs-api.onemini.top/9683548m0)。本文只展开型号专属参数。表中“默认值”是参数说明中的默认选项；未指定的字段不额外推断默认值、枚举或上限。所有条件规则需要同时满足；传入 false 仍算“提供了该字段”。

## 调用前设置

将下面的占位内容替换为你自己的 API Key；后续命令统一使用 `API_KEY`。命令按 Bash 写法展示。

```bash
export API_KEY='替换为你的 API Key'
```

## 型号差异与操作选择

- wan2.6、wan2.6-i2v、wan2.6-i2v-flash 是独立型号。wan2.6 为 5／10／15 秒、默认 720p；flash 必填单张 image_urls，2–15 秒、默认 1080p；i2v 未列出固定时长和清晰度选项，不能沿用另两型号的范围／默认值。
- wan2.6／2.5 的 audio_url 是单个音频 URL。audio 与 generate_audio 是不同公开字段，未声明统一优先级。shot_type、template 只在参数表出现的型号使用。
- wan2.7 禁止同时传 image_urls／image_with_roles，也禁止 video_urls／audio_url 同传；r2v 必填 prompt，且 image_with_roles／video_urls 至少一个；含视频时 duration 上限 10 秒。
- wan2.7-videoedit 必填 video_urls；duration=0 或省略表示沿用完整输入时长，也可显式选 2–10 秒，0 不是通用自动值。
- wan3.0-video／prime 支持文字、图片、视频、音频及 file_url／link_url 等入口，file_url 与 link_url 互斥。参数规则虽列 duration=-1，当前接口暂不接受该自动时长值；当前调用使用 2–30 秒正整数，示例不用 -1。
- Wan 2.7／3.0 清晰度有大写 P 等精确枚举，不能统一改写。

## 参数与提交示例

参数表包含嵌套字段；数组元素以 `[]` 标记。“父项出现时必填”不强制可选父字段存在。同系列型号也可能采用不同字段或组合限制，请按准确型号调用。示例素材 `example.com` 为占位符，必须替换为可公开读取的真实素材 URL。

## `wan2.5-preview`

| 参数 | 中文含义 | 类型 | 必填 | 默认值 | 枚举／范围／说明 |
|---|---|---|---|---|---|
| `aspect_ratio` | 画面比例 | 字符串 | 否／按组合规则 | 未声明 | 未声明额外枚举或范围 |

| `audio_url` | 参考音频 URL | 字符串 | 否／按组合规则 | 未声明 | 未声明额外枚举或范围 |

| `first_frame_image` | 首帧图片 URL | 字符串 | 否／按组合规则 | 未声明 | 未声明额外枚举或范围 |
| `generate_audio` | 生成声音 | 布尔值 | 否／按组合规则 | 未声明 | 未声明额外枚举或范围 |
| `image_urls` | 参考图片 URL 列表 | 数组 | 否／按组合规则 | 未声明 | 至少 1 项；至多 1 项；元素：字符串 |
| `image_with_roles` | 带角色的图片列表 | 数组 | 否／按组合规则 | 未声明 | 至少 1 项；带首帧、尾帧或参考图角色的图片列表。 |
| `image_with_roles[].role` | 素材／消息角色 | 字符串 | 否／按组合规则 | 未声明 | 未声明额外枚举或范围 |
| `image_with_roles[].url` | URL 兼容字段 | 字符串 | 父项出现时必填 | 未声明 | 未声明额外枚举或范围 |
| `last_frame_image` | 尾帧图片 URL | 字符串 | 否／按组合规则 | 未声明 | 未声明额外枚举或范围 |
| `model` | 模型 ID | 字符串 | 是 | 未声明 | 固定为 `"wan2.5-preview"` |
| `negative_prompt` | 排除内容 | 字符串 | 否／按组合规则 | 未声明 | 至多 500 个字符 |
| `nsfw_check` | 内容审核选项 | 布尔值 | 否／按组合规则 | `false` | 未声明额外枚举或范围 |
| `prompt` | 生成描述／提示词 | 字符串 | 否／按组合规则 | 未声明 | 未声明额外枚举或范围 |
| `prompt_extend` | 扩展提示词 | 布尔值 | 否／按组合规则 | `true` | 未声明额外枚举或范围 |
| `resolution` | 清晰度 | 字符串 | 否／按组合规则 | `"720p"` | 可选 `"480p"`、`"720p"`、`"1080p"` |

| `video_urls` | 输入／参考视频 URL 列表 | 数组 | 否／按组合规则 | 未声明 | 至少 1 项；元素：字符串；模型支持时使用的参考视频 URL 列表。 |
| `watermark` | 水印 | 布尔值 | 否／按组合规则 | `false` | 未声明额外枚举或范围 |

### 必填、互斥与条件规则

- 必填：`model`。
- 至少提供 `prompt` 或 `image_urls`。
- 当`resolution` 为 `"480p"`时，`size`（如提供）可选 `"16:9"`／`"9:16"`／`"1:1"`。

输入模式：文字生成、图片参考生成、音频参考生成。各模式均须满足本型号的必填和组合限制。

### 来源任务

本型号不提供本站草稿／续写来源任务字段；素材 URL 与任务 ID 不能混用。

### 提交示例

```bash
curl --fail-with-body -sS "https://api.onemini.top/v1/videos/generations" \
  -H "Authorization: Bearer ${API_KEY}" \
  -H "Content-Type: application/json" \
  --data-raw '{
  "model": "wan2.5-preview",
  "prompt": "镜头缓慢推进，清晨阳光照亮森林，画面自然平稳",
  "duration": 5,
  "resolution": "720p"
}' \
  -o submit.json
```

| `image_with_roles` | 带角色的图片列表 | 数组 | 否／按组合规则 | 未声明 | 未声明额外枚举或范围 |
| `image_with_roles[].role` | 素材／消息角色 | 字符串 | 父项出现时必填 | 未声明 | 可选 `"first_frame"`、`"last_frame"`、`"reference_image"` |
| `image_with_roles[].url` | URL 兼容字段 | 字符串 | 父项出现时必填 | 未声明 | 至少 1 个字符 |
| `last_frame_image` | 尾帧图片 URL | 字符串 | 否／按组合规则 | 未声明 | 未声明额外枚举或范围 |
| `link_url` | 链接参考地址 | 字符串 | 否／按组合规则 | 未声明 | 未声明额外枚举或范围 |
| `model` | 模型 ID | 字符串 | 是 | 未声明 | 固定为 `"wan3.0-video-prime"` |
| `nsfw_check` | 内容审核选项 | 布尔值 | 否／按组合规则 | `false` | 未声明额外枚举或范围 |
| `prompt` | 生成描述／提示词 | 字符串 | 否／按组合规则 | 未声明 | 至多 20000 个字符 |
| `resolution` | 清晰度 | 字符串 | 否／按组合规则 | `"1080P"` | 可选 `"480P"`、`"480p"`、`"720P"`、`"720p"`、`"1080P"`、`"1080p"` |
| `seed` | 随机种子 | 整数 | 否／按组合规则 | 未声明 | ≥ `0`；≤ `2147483647` |
| `size` | 画面尺寸／比例 | 字符串 | 否／按组合规则 | `"adaptive"` | 可选 `"adaptive"`、`"16:9"`、`"4:3"`、`"1:1"`、`"3:4"`、`"9:16"` |
| `video_urls` | 输入／参考视频 URL 列表 | 数组 | 否／按组合规则 | 未声明 | 至多 5 项；元素：字符串 |
| `watermark` | 水印 | 布尔值 | 否／按组合规则 | `false` | 未声明额外枚举或范围 |

### 必填、互斥与条件规则

- 必填：`model`。
- 至少提供 `prompt` 或 `image_urls` 或 `image_with_roles` 或 `video_urls` 或 `audio_urls` 或 `audio_url` 或 `file_url` 或 `link_url`。
- 不得同时提供 `file_url`、`link_url`。

输入模式：文字生成、图片参考生成、视频参考生成、音频参考生成。各模式均须满足本型号的必填和组合限制。

### 来源任务

本型号不提供本站草稿／续写来源任务字段；素材 URL 与任务 ID 不能混用。

### 提交示例

```bash
curl --fail-with-body -sS "https://api.onemini.top/v1/videos/generations" \
  -H "Authorization: Bearer ${API_KEY}" \
  -H "Content-Type: application/json" \
  --data-raw '{
  "model": "wan3.0-video-prime",
  "prompt": "镜头缓慢推进，清晨阳光照亮森林，画面自然平稳",
  "duration": 5,
  "resolution": "1080P"
}' \
  -o submit.json
```

## 查询与下载

提交成功返回 HTTP 202，任务对象位于 `data`。以下命令从 `data.task_id` 读取本次任务 ID。

```bash
TASK_ID=$(jq -er '.data.task_id' submit.json)
curl --fail-with-body -sS "https://api.onemini.top/v1/media/tasks/${TASK_ID}" \
  -H "Authorization: Bearer ${API_KEY}" \
  -o task.json
jq '.data | {task_id, model, status, result, error}' task.json
```

未到 `succeeded` 时按公共指南继续查询同一任务；不要把“已接收”当成媒体已经生成。成功后才执行下载：

```bash
MEDIA_URL=$(jq -er '.data.result.videos[0].url[0]' task.json)
curl --fail --location "$MEDIA_URL" --output output.mp4
```

示例取第一项；有多个结果时遍历真实结果列表。素材／结果 URL 不需要转发本站 API Key。文件后缀应按实际输出格式调整。

视频结果 URL 从 `data.result.videos[].url[]` 读取；本组媒体任务没有通用视频 content 下载实现。不能把原生 `/v1/videos/{id}/content` 当成本组任务的下载路由。

停止未外发请求与上游任务撤销不是同一功能；取消和幂等说明统一见[任务公共指南](https://docs-api.onemini.top/9683548m0)。本组不承诺可撤销已外发任务。
